# 学びの地図 v2 再構築計画

## 目的

このプロジェクトは、小学校で学ぶ内容を一覧化するだけでなく、学習内容の前後・関連・発展をたどり、子どもが必要な学びに戻れるようにする。また、同じデータをAI・教材開発が参照できる共通基盤にする。

## 二つの利用者

1. 子ども・先生：学年と教科から学びを見渡し、学習項目の詳細、前提候補、関連、発展、復習候補をたどる。
2. AI・教材開発者：安定したID、学習目標、学年配当の根拠、学習関係、つまずき・支援、表現方法、出典・確認状態を機械的に取得する。

## 採用する情報設計

- 入口は学年別・教科別・キーワード検索。
- 一覧は学年の目安と分野ごとのまとまりを見渡せる構成。
- 詳細画面では、前に学んだこと／今の学び／この先につながること／関連する学びを区別する。
- 学習ネットワークは最初から全件を描画せず、選択した項目の直接の隣接項目から段階的にたどる。
- 「復習候補」は単なる前提関係と同一視しない。誤答・困り方・必要な理解に対応づける別データとして管理する。
- 学年配当は公式の確定配当とプロジェクト上の候補を区別する。
- 全教科を対象に設計するが、未整備の教科・領域は未収録と明示し、架空の項目を表示しない。

## データ原則

1. 既存 topics.json / dependencies.json と安定IDは移行資産として保持する。
2. 学習項目、学年配当、学習関係、復習支援、表現モデル、出典の確認状況を別々に管理する。
3. 「公式資料に明記」「資料に基づく編集上の整理」「教員レビュー」「未確認」を混同しない。
4. 必要な前提、推奨前提、関連、発展、活用、繰り返し育つ力を別の関係型として扱う。
5. 学年配当は初出候補・継続・活用を区別する。grades だけから公式配当を推定しない。
6. 項目統合・分割時は旧IDを削除せず、後継IDと互換性を維持する。
7. タクソノミーは「何を学ぶか」の単位、教材・問題の粒度は別レイヤーにする。
8. 子ども向け表示名・説明と、内部の正式名称・編集注記を分ける。
9. すべての関係には理由・根拠種別・確認状態を付ける。
10. 未確認データを公開確認済みとして扱わない。

## 推奨するデータ領域

- data/topics.json：学習項目と目標
- data/dependencies.json：学習項目間の関係
- data/learning-support.json：つまずき、見られる状態、復習候補、支援の順序
- data/representation-models.json：図・式・表・言葉・観察・実験などの表現
- data/curriculum-standards.json：公式資料と領域
- data/curriculum-code-mapping.json：公式コード候補と意味的対応の確認状況
- data/manifest.json：データ版、件数、確認状態、更新情報

新規データ領域はスキーマと検証処理を先に整え、確認済みの根拠がない診断・復習対応を大量に作らない。

## 教科の扱い

全教科を設計対象にする。国語・算数・社会・理科の既存データを維持・点検し、生活、音楽、図画工作、家庭、体育、外国語活動、外国語、道徳、総合的な学習の時間、特別活動を順次整理する。

教科の特性に合わせ、知識・技能の系統、探究技能、表現・鑑賞、態度・経験、資質・能力の育ちを区別する。すべてを算数型の前提関係に押し込まない。

## UI原則

- タブレット優先、スマートフォンでも操作可能。
- 学年・教科・分野から一覧に入れる。検索は補助。
- 一覧は大きな学習まとまりから詳細へ進む。
- 詳細は直接関係を中心に表示し、全ネットワークを一度に見せない。
- 関係の種類と確認状況を表示する。
- 子ども向けに内部ID、編集用語、未確認の断定表現を出さない。
- 横スクロールを必須にせず、端末幅に応じて再配置する。
- 読み込み失敗・データ欠落・検索0件を明確に案内する。

## 現行資産の扱い

既存データのID・出典・説明・レビュー記録を可能な限り維持する。件数だけを目標に統合・分割しない。既存の教科別監査、学年配当レビュー、コード照合、表現モデルを再利用する。古い監査記録は履歴として残し、最新の共通データと区別する。

## v2 試作の範囲

このブランチの site/v2/ は、現行の静的JSONを読み込む画面試作である。国語・算数・社会・理科の収録済みデータを表示し、学年・教科・検索で絞り込み、選択項目の直接関係を表示する。復習診断や未収録教科の完成を意味しない。

## 完成判定

- 全教科の収録範囲と未収録範囲が明示されている。
- 学習項目と関係に出典・根拠種別・確認状態がある。
- 前提・関連・発展・活用・復習候補が意味的に区別される。
- 復習候補は、つまずきの種類と結びつき、根拠のある内容だけが表示される。
- AIが安定IDで学習項目と隣接関係を取得できる。
- データ検証でID重複、参照切れ、誤った循環、型不整合を検出できる。
- タブレット・スマートフォン・キーボード操作で主要導線が使える。
- 公開版の切り替えは、別途確認と判断を経て行う。
