# 出版社の系統資料の参照方針

算数の学習項目と学年間のつながりを整理する際は、文部科学省の学習指導要領・解説を基準にし、啓林館や東京書籍など複数社の公開資料を補助的に参照する。

- 啓林館「算数・数学 内容系統一覧表」など：学年をまたぐ内容のつながりを検討する。
- 東京書籍「領域別系統表」「図解系統表」「線分図・数直線の系統」など：領域の配列や図的モデルの発展を検討する。
- 出版社ごとの単元配列は編集上の構成として扱い、全国共通の唯一の順序とはみなさない。
- 出版社の文章・図表・図版をそのまま転載せず、独自の学習項目と関係として再構成する。
- 参照した資料のURL、対象年度、確認日、そこから導いたプロジェクト独自の判断を記録する。

## 参照先

- 啓林館「授業支援・サポート資料」: https://shinko-keirin.co.jp/keirinkan/sho/sansu/support/
- 東京書籍「新編 新しい算数の資料ダウンロード」: https://ten.tokyo-shoseki.co.jp/text/shou//download/sansu/
- 文部科学省「小学校学習指導要領解説 算数編」: https://www.mext.go.jp/a_menu/shotou/new-cs/1387014.htm
