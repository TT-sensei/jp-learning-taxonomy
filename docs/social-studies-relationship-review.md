# 社会タクソノミー：項目間の関係候補

更新日：2026-10-20（初期候補を継続見直し中）

## 目的と扱い

項目を一覧で終わらせず、既習内容・資料活用・社会的な仕組みのつながりを表すための初期候補を整理する。ここで示す関係はプロジェクトの学習設計案であり、学習指導要領が定める必須の前提条件や公式の系統表ではない。

## 1. 学習内容どうしの関係候補

| 関係元 | 関係先 | 関係の種類 | 確認ポイント |
|---|---|---|---|
| 身近な地域や市区町村の様子 | 都道府県の位置・地形と交通・主な産業 | 見方の拡張 | 身近な地域の位置関係を、都道府県・日本の地図へ広げる。必須前提と断定しない。 |
| 地域の人々の仕事と生産・販売 | 農業の生産と食料 | 比較・発展 | 生産や販売の工夫を、食料生産の仕組みへつなぐ。 |
| 地域の人々の仕事と生産・販売 | 工業生産と貿易 | 比較・発展 | 地域の仕事と全国的な生産・流通の共通点・違いを比較する。 |
| 市区町村の移り変わり | 年表・歴史資料を読み取る | 資料活用 | 写真や地図の比較を、時期の変化を示す資料読解へつなぐ。 |
| 自然災害から地域を守る | 日本の地形と気候 | 概念の橋渡し | 地域の災害リスクと自然条件の関係を考える。地域差が大きいため具体例を固定しない。 |
| 火災から地域を守る | 事故や事件から地域を守る | 比較 | 安全を守る機関の役割と協力の仕組みを比較する。 |
| 自然災害から地域を守る | 自然災害と国土の保全 | 対象範囲の拡張 | 第4学年は地域の関係機関・住民の活動、第5学年は自然条件と国土全体の災害・保全を扱う。前提順序ではなく、視野の広がりを示す関連候補。 |
| 飲料水・電気・ガスの供給 | 廃棄物の処理と再利用 | 生活基盤の比較 | 資源の確保・処理、関係機関、住民の協力を比べる。 |
| 県内の特色ある地域とまちづくり | 農業の生産と食料 | 地域と産業 | 地域の特色を産業の具体的な事例と関連付ける。 |
| 日本の地形と気候 | 自然環境と人々のくらし | 学習上のつながり | 自然条件と生活の工夫を関係付ける。 |
| 農業の生産と食料 | 食料生産とわたしたちの生活 | 概念の橋渡し | 生産の工夫と消費・流通をつなぐ。公式内容の範囲は要確認。 |
| 工業生産と貿易 | 交通網と物流 | 学習上のつながり | 原材料や製品が運ばれる仕組みを、工業生産の視点から捉える。 |
| 情報産業と情報活用 | 統計・グラフを読み取る | 資料・情報の橋渡し | 情報を生み出す仕組みと、資料を読み解く技能を同一視しない。 |
| 環境を守る取組 | 自然環境と人々のくらし | 課題の検討 | 自然条件への適応と、環境への負荷を減らす社会的な取組を区別しつつ関連付ける。 |
| 戦国の世の統一 | 江戸幕府と社会の安定 | 時代のつながり | 政治の統一から幕府の仕組み・社会の変化へつなぐ。 |
| 江戸幕府と社会の安定 | 明治の改革と近代日本の発展 | 時代のつながり | 政治・社会の仕組みの変化を比較する。 |
| 明治の改革と近代日本の発展 | 戦争と人々の暮らし | 時代のつながり | 近代国家の形成から戦争・戦後の変化までを、因果を単純化せず資料で検討する。 |
| 戦争と人々の暮らし | 戦後の日本の出発とくらしの向上 | 時代のつながり | 戦後の社会変化と国際社会における役割を関連付ける。 |
| 日本国憲法と政治の基本 | 国会の働きと法律 | 制度のつながり | 憲法の原則と国会の役割を結び付ける。 |
| 国会の働きと法律 | 内閣・行政・裁判所の働き | 制度の比較 | 立法・行政・司法の役割を区別して捉える。 |
| 地方公共団体と住民 | 社会の課題について考え判断する | 市民参加 | 地域の課題を資料や複数の立場に基づいて検討する。 |
| つながりの深い国々のくらしと日本の国際協力 | 戦後の日本の出発とくらしの向上 | 国際理解 | 戦後の日本と国際社会の関係を歴史・現代の両面から捉える。 |

## 2. 横断的な資料活用の関係

| 技能 | 活用先の例 | 設計上の注意 |
|---|---|---|
| 地図・地球儀を読み取る | 地域、市区町村、都道府県、日本の国土、産業の分布 | 学年によって扱う地図の範囲や縮尺が異なる。 |
| 統計・グラフを読み取る | 産業、人口や地域の変化、環境、国際社会 | 数値の傾向と、その原因についての解釈を分ける。 |
| 年表・歴史資料を読み取る | 市の移り変わり、各時代の歴史、近代化、戦後 | 資料が示す事実と、そこから導く解釈を分ける。 |
| 観察・聞き取り・現地調査 | 地域の様子、仕事、公共施設、地域の安全 | 調査の目的、相手への配慮、記録の正確さを確認する。 |
| 地域や時代を比較する | 産業、地域の特色、歴史の変化 | 違いを挙げるだけでなく、比較する条件をそろえる。 |
| 資料を根拠に説明する | 全学年の調査・考察 | 資料に書かれていることと、自分の考えを区別する。 |
| 社会の課題について考え判断する | 地域の安全、環境、政治、国際協力 | 一つの答えに誘導せず、複数の立場・根拠・価値を扱う。 |

## 3. 次の確認

1. 文部科学省の社会編解説と各関係候補を照合し、公式内容項目の範囲を越えていないか確認する。
2. 「情報産業」「食料生産とわたしたちの生活」など、草案独自の細分化が必要か、公式項目の子項目として管理すべきか確認する。
3. 歴史項目の区切りを、公式解説で扱う主な歴史的事象・人物・文化に合わせて調整する。
4. 公式コードと学年配当の照合後に、関係候補をデータ化する。検証前の関係を学習の強制的なロック条件には使わない。
