# 社会タクソノミー：公式内容との照合レビュー

更新日：2026-10-18  
主資料：文部科学省「小学校学習指導要領（平成29年告示）解説 社会編」  
https://www.mext.go.jp/content/20230308-mxt_kyoiku02-100002607_003.pdf

## 1. 今回確認したこと

文部科学省の社会編解説を参照し、草案の候補項目を公式の学年別内容のまとまりと照らし合わせた。草案は公式項目をそのまま写した一覧ではなく、公式の大きな内容を、教材・学習履歴・関連づけに使いやすい単位へ分けるプロジェクト独自の分類である。

今回、第3学年の公式内容「地域の発展に尽くした先人」に相当する候補が欠けていることを確認し、「地域の発展に尽くした先人」を追加した。候補は42件から43件になった。

## 2. 学年別の照合メモ

| 学年 | 公式内容の主なまとまり | 草案との照合・修正課題 |
|---|---|---|
| 第3学年 | 身近な地域・市区町村、地域の生産や販売の仕事、地域の発展に尽くした先人、市の様子の移り変わり | 「地域の発展に尽くした先人」を追加済み。地図・方位は独立した公式内容項目というより、地域の様子を調べる技能・学習内容として位置づけを再確認する。 |
| 第4学年 | 都道府県の位置・様子、人々の健康や生活環境を支える事業、自然災害から地域を守る活動、県内の特色ある地域 | 「消防」「警察」「飲料水」「ごみ」「文化・産業」を一律に独立した公式項目と見なさない。公式の大きな内容の下位候補として親項目を設定し、地域の実情に応じる内容と全国共通の枠組みを分ける。 |
| 第5学年 | 我が国の国土と国民生活、食料生産、工業生産、情報と産業・国民生活の関わり | 農業・水産業は食料生産の具体例として扱われる。林業・森林、自然災害・環境保全は国土・自然環境との関係を明確にする。「食料生産とわたしたちの生活」「交通網と物流」は独立した公式内容と断定せず、公式内容の下位候補・横断的な関連として整理する。 |
| 第6学年 | 国家・社会の発展に大きな働きをした先人と文化遺産、政治の働きと日本の政治の考え方、世界の国々と日本の国際的な役割 | 歴史を時代別に分けること自体はプロジェクトの整理方法。公式の内容項目を親にして、人物・出来事・文化の候補を子項目として対応づける。憲法・国会・内閣・裁判所・地方自治も、公式項目との対応を確認してから確定する。 |

## 3. 現時点で分かった主な設計上の問題

1. 公式の内容項目と、授業で扱う具体的な事例やプロジェクト独自の子項目が同じ階層に並んでいる。今後は公式内容を親、具体的な学習トピックを子として対応づける。
2. 第4学年の消防・警察などは、独立した公式内容項目だと先に決めず、「健康や生活環境を支える事業」「地域の安全」「自然災害」などのどの内容に対応するかを個別に確かめる。
3. 第5学年の農業・水産業・林業を公式の独立項目のように並べると、公式内容の構造と誤解される可能性がある。食料生産の具体例、国土・森林資源・環境の学習、産業間の関連を分けて管理する。
4. 第6学年の歴史の区切りは、均等な時代分割ではなく、公式解説が例示する人物・出来事・文化との対応を記録する。
5. 地図、統計、年表、聞き取り、比較、根拠に基づく説明、社会的な判断は、公式の内容項目と同じ種類ではない。横断的な技能・思考の分類として扱い、公式コードを直接割り当てない。

## 4. 次に行う修正

- 各トピックに「対応する公式内容の親項目」「対応状態」「確認根拠」を追加する。
- 第3・4学年の内容項目と候補を一件ずつ照合し、消防・警察・飲料水・ごみ・文化・産業の位置づけを整理する。
- 第5学年は国土、食料生産、工業生産、情報と産業の公式のまとまりを親項目として再編する。
- 第6学年は歴史・政治・国際関係の公式のまとまりを親項目にし、各候補が公式の例示や内容の範囲を超えていないか確認する。
- 学習指導要領コード表の実データを照合し、確実に一致した場合だけ公式コードを登録する。公式内容項目の番号と学習指導要領コードは区別する。

## 5. 確度と出典

出典は文部科学省の社会編解説。公式内容の大きな構造を確認した段階であり、草案の全トピック・学年・公式コードを一件ずつ確定したわけではない。公式の文言の長い転載は避け、独自の要約で記録している。
