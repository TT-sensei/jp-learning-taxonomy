# 社会タクソノミー：分類・学年別内容の初期レビュー

更新日：2026-10-18  
参照：文部科学省「小学校学習指導要領（平成29年告示）解説 社会編」  
https://www.mext.go.jp/content/20230308-mxt_kyoiku02-100002607_003.pdf

## 1. この草案の目的

社会科の学習内容を、学年ごとの公式内容を骨格にしながら、再利用できる項目ID、横断的な資料活用技能、項目間のつながりへ整理するための初期草案である。候補は42件。全項目の公式内容・学年配当・公式コードを照合済みという意味ではない。

社会科では、理科のような単一の概念系列に全内容を押し込まず、地域学習、国土・産業、歴史、政治・国際理解を分ける。地図・統計・年表・聞き取りなどの技能は、各単元で繰り返し使う横断項目として別に持つ。

## 2. 学年ごとの構造候補

| 学年 | 主なまとまり | 粒度・確認上の注意 |
|---|---|---|
| 第3学年 | 市区町村の様子、地域の仕事、市の移り変わり | 地域教材の固有名詞はデータ本体に固定せず、地域別リソースで扱う。 |
| 第4学年 | 都道府県、自然災害、消防・警察、飲料水、ごみ、地域産業・文化 | 地域の安全と生活基盤を別項目にしつつ、関係機関の協力を関係データでつなぐ。 |
| 第5学年 | 国土、自然環境、農林水産業、工業、情報、物流、環境 | 「産業」を大きな一項目にまとめず、主要な生産・社会的役割を分ける。 |
| 第6学年 | 歴史、憲法、国会・行政・司法、地方自治、国際社会 | 歴史を時代別の候補に分け、政治の仕組みは歴史項目と混同しない。 |
| 横断 | 地図・統計・年表、現地調査、比較、根拠に基づく説明、判断 | 公式の学年別内容そのものではなく、資料活用・調査のプロジェクト分類。 |

## 3. 初期レビューで重視する境界

- 第3学年の地域学習は、全国共通の学習枠と、自治体ごとに異なる具体的な地域教材を分離する。
- 第4学年の「自然災害」「消防」「警察」「飲料水」「ごみ」は、生活を支える仕組みとして関連するが、同一項目にまとめない。
- 第5学年の農業・林業・水産業・工業は、生産や流通の共通点を持つ一方、対象や仕組みが異なるため別候補にする。
- 第5学年の「情報産業」と、各産業での情報活用を混同しない。公式内容の範囲を解説で再確認する。
- 第6学年の歴史項目は、時代を機械的に均等分割するのではなく、公式解説に示された主な歴史的事象・人物・文化のまとまりに照らして再調整する。
- 第6学年の政治は、憲法、国会、内閣・行政、裁判所、地方自治、国際社会を別項目として候補化しているが、公式内容項目の粒度と一致するかは未確認。
- 「社会の課題について考え判断する」は単元知識と区別し、根拠や複数の立場を踏まえる横断的な技能候補として扱う。

## 4. 公式資料との照合で次に行うこと

1. 解説の第3〜6学年の各内容項目と、草案の各項目を一つずつ対応させる。
2. 公式項目を複数の候補に分けた場合は、プロジェクト独自の細分化であることと親項目を記録する。
3. 公式項目より広い候補は、分割または説明の限定を検討する。
4. 候補学年、初出・継続学年、地域教材と全国共通内容の境界を確認する。
5. 文部科学省の学習指導要領コード表82V12の実データを取得し、確実に一致するものだけ公式コードを登録する。内容項目番号を公式コードと取り違えない。
6. 関連候補を設計するときは、公式の配列と、プロジェクトが考える学習上の関連を別々に管理する。

## 5. 出典と確度

主な出典は文部科学省の社会編解説である。項目名と説明は確認作業のための独自要約。現時点では公式コードとの照合を行っていないため、全項目を「要確認」としている。

この文書は初期の分類レビューであり、学習指導要領の完全な網羅性、公式コード、項目間の正式な前提関係を保証しない。
