# 社会科・公式内容照合と修正記録（2026-10-20）

## 対象と判断ルール

対象は `data/topics.json` の社会44項目（横断的な技能を含む）。基準は文部科学省「小学校学習指導要領（平成29年告示）解説 社会編」の第2章第2節「社会科の内容構成」と、第3章の学年ごとの内容。学習指導要領コードの個別照合はまだ実施していない。

公式解説：https://www.mext.go.jp/content/20230308-mxt_kyoiku02-100002607_003.pdf

このレビューでは、公式の学年・内容構成がはっきり確認できたものをもとに候補学年のずれを修正した。項目の細かな説明やコードがすべて確認済みという意味ではない。データの `reviewStatus` は引き続き `needs-review` とする。

## 第2回：項目の範囲・不足・重複の再照合

### 第3学年：生産・販売と地域の安全

現行の内容（2）「地域に見られる生産や販売の仕事」では、生産の種類・産地の分布・仕事の工程に加え、販売における消費者の多様な願い、販売の工夫、他地域や外国との関わりを扱う。そのため `jp.elem.social.municipality-work` の説明を具体化した。

内容（3）「地域の安全を守る働き」は、消防と事故防止の二つの候補に分けているが、公式の内容の取扱いでは火災と事故の両方を取り上げ、どちらかに重点を置く工夫ができる。二つのプロジェクト項目は公式内容そのものを二分した公式コードではないので、片方のみで内容（3）全体を満たすように見せない説明に更新した。

### 第4学年：都道府県の学習

文部科学省解説の第4学年内容（1）は、都道府県の名称と位置、県の地理的位置、県全体の地形や主な産業、交通網、主な都市の位置を扱う。そこで `jp.elem.social.prefecture-land` の説明をこの範囲に合わせた。「気候」を中心に置く表現は第5学年の国土の地形・気候と混同しやすいため外した。

内容（2）「人々の健康や生活環境を支える事業」では、内容の取扱いにより供給事業は飲料水・電気・ガスから一つ、廃棄物処理はごみ・下水から一つを選んで取り上げる。したがって、共通データでは `water-supply` と `waste-management` の項目名・説明を選択可能な公式のまとまりに合わせ、電気・ガス・下水を別々の必修項目として追加するのではなく、地域の指導計画による事例選択を明記した。これは不足ではなく、公式の選択条件をデータに反映するための修正である。

内容（3）「自然災害から人々を守る活動」では、過去に県内で起きた地震・津波・風水害・火山災害・雪害などから地域に合った事例を選び、県庁や市役所による防災情報の発信、避難体制の確保、自衛隊など国の機関との関わりを扱う。そこで `jp.elem.social.disaster-prevention` の説明を具体化し、第5学年の国土全体の自然条件と自然災害・国土保全を扱う項目とは対象範囲を分けた。

内容（5）「県内の特色ある地域の様子」では、地場産業、国際交流、自然環境や伝統文化などの地域資源を守り生かす地域、まちづくりや観光などが扱われる。`jp.elem.social.prefecture-industry` はこの内容が伝わるよう、名称・説明・子ども向け表示を更新した。`jp.elem.social.prefecture-culture` は文化財や年中行事の継承に焦点を置き、特色ある地域の資源活用や観光との重複を抑える。

### 第5学年：国土の自然環境と国民生活

公式内容（5）には、自然災害と国土保全、森林資源の働き、公害の防止と生活環境という観点がある。従来の社会項目には森林・環境保全に関する項目はあったが、自然災害の発生と自然条件の関係、国や都道府県の対策を第5学年で学ぶ項目が明確に存在しなかった。そのため `jp.elem.social.national-disaster-prevention` を新設した。

第4学年の `jp.elem.social.disaster-prevention` は地域の行政・関係機関・住民の活動を扱い、新設項目は国土全体の自然条件と保全、国・都道府県による対策を扱う。両者は同じ項目の重複ではなく、対象範囲の広がりとして `related-learning` の関係を追加した。これは編集上の提案であり、公式に定められた前提順序ではない。

### 第6学年：公式内容番号の基準

現行の小学校学習指導要領（平成29年告示）では、第6学年の公式内容は、（1）「我が国の政治の働き」、（2）「我が国の歴史上の主な事象」、（3）「グローバル化する世界と日本の役割」の順に整理されている。今回の照合ではこの順番を明示的に再確認し、政治の項目に使っていた（2）を（1）へ、歴史の時代別項目に使っていた（1）を（2）へ修正した。公式内容番号をプロジェクト独自の表示順や話題の並び順から推測しない。

### 第6学年：歴史・国際理解の範囲

第6学年の歴史内容（2）は、時代の大きな流れに加えて、狩猟・採集や農耕、古墳と大和政権、大陸文化・大化の改新・大仏造営、貴族文化、源平の戦い・鎌倉幕府・元との戦い、室町文化、キリスト教の伝来と天下統一、江戸幕府・参勤交代・鎖国、町人文化・新しい学問、明治維新・文明開化、憲法制定・日清日露戦争・条約改正、第二次世界大戦・日本国憲法・戦後の生活向上などを、選択した人物や文化遺産を中心に扱う。小学校の歴史は全事象を網羅する通史ではないが、現在の広い時代別項目だけでは各内容が画面で伝わりにくいため、説明文に主な事象を具体的に記載した。

`jp.elem.social.war-and-recovery` は戦争と人々の生活への影響、`jp.elem.social.postwar-japan` は戦後の改革・民主的な国家の出発・国民生活の向上・国際社会での役割に焦点を分けた。これらは公式内容（2）の内部をプロジェクト独自に分けた学習項目であり、別々の公式内容項目を意味しない。`jp.elem.social.international-relations` には、つながりの深い国々のくらしや文化の違い、国際交流、国際連合と国際協力を明記し、公式内容（3）の要素が欠けて見えないようにした。

### 第6学年：政治の内容の取扱い

第6学年内容（1）「我が国の政治の働き」についても、説明文が「憲法・国会・内閣・裁判所」の名称を並べるだけにならないよう、内容の取扱いを再確認した。現行の文部科学省解説は、憲法の定める国家・国民生活の基本と国民の権利・義務、議会政治と選挙、国会・内閣・裁判所の役割と相互の関連、裁判制度への国民参加（裁判員制度）、租税の役割、国や地方公共団体の政治が暮らしを支える働きを扱うよう示している。また、政治の取組の事例は、社会保障、自然災害からの復旧・復興、地域の開発や活性化などから選択して扱う。

この確認に基づき、`jp.elem.social.constitution` は国家の基本・天皇の地位・権利と義務・憲法の基本的な考え方、`jp.elem.social.diet` は議会政治・選挙・法律・予算、`jp.elem.social.government-courts` は三権の役割と相互の関連・裁判員制度・租税、`jp.elem.social.local-government` は国と地方公共団体による政策や計画、予算と暮らしの関係を扱うように説明を整理した。

これら4項目は、公式内容（2）を理解しやすくするためのプロジェクト独自の細分化であり、別々の公式内容番号や公式コードを意味しない。地域や学校の具体例により全ての取組を均等に扱うと決めつけず、公式解説で選択可能とされる事例を選ぶ形を残す。

## 第3回：公式の内容項目とプロジェクト独自の細分化を再確認（2026-10-20）

| 第4学年 (1) 都道府県の様子 | `prefecture-land`。都道府県の名称・位置、地形、主な産業、交通網、主な都市の位置を中心とする。 |
| 第4学年 (2) 人々の健康や生活環境を支える事業 | `water-supply` と `waste-management`。それぞれ供給事業は飲料水・電気・ガスから一つ、廃棄物処理はごみ・下水から一つを選ぶ内容の取扱いを記録する。 |
| 第4学年 (3) 自然災害から人々を守る活動 | `disaster-prevention`。地域の行政・関係機関・住民の活動を扱う候補。 |
| 第4学年 (4) 県内の伝統や文化，先人の働き | `prefecture-culture` と `community-predecessors`。文化財・年中行事の継承と、先人の働き・願い・苦心を分ける独自の整理。 |
| 第4学年 (5) 県内の特色ある地域の様子 | `prefecture-industry`。伝統的な技術を生かす地場産業、国際交流、地域資源の保護・活用などの地域を事例候補とする。`prefecture-culture` の文化財・年中行事の継承と混同しない。 |
| 第5学年 (1) 我が国の国土の様子と国民生活 | `japan-location`、`japan-landforms-climate`、`natural-environment-life`。国土の位置・地形・気候と、人々の生活との関わりを整理する候補。 |
| 第5学年 (2) 我が国の農業や水産業における食料生産 | `agriculture` と `fisheries` を生産の具体例として整理し、`food-life` は生産・流通・消費をつなぐプロジェクト独自のまとめ項目とする。各業種をすべての地域で個別に教えると断定しない。 |
| 第5学年 (3) 我が国の工業生産 | `industrial-production` が中心。`transport-trade` は産業の内容をつなぐ横断的な整理で、公式の独立内容項目ではない。 |
| 第5学年 (4) 我が国の産業と情報との関わり | `information-industry`。情報産業、情報の収集・選択・編集と、情報化が産業・生活に果たす役割を確認対象にする。 |
| 第5学年 (5) 我が国の国土の自然環境と国民生活との関連 | `national-disaster-prevention`、`forestry`、`environment-protection`。自然災害・国土保全、森林資源、公害防止・生活環境の観点を区別する。 |
| 第6学年 (1) 我が国の政治の働き | `constitution`、`diet`、`government-courts`、`local-government`。公式内容の内部を理解しやすく分けたプロジェクト独自の候補で、各項目が独立した公式内容や公式コードを持つ意味ではない。 |
| 第6学年 (2) 我が国の歴史上の主な事象 | `ancient-japan`、`medieval-japan`、`unification`、`edo-society`、`modernization`、`war-and-recovery`、`postwar-japan`。時代別に見渡すための独自分類。主な人物・事象・文化遺産の扱いは、別途チェックリストで確認する必要がある。 |
| 第6学年 (3) グローバル化する世界と日本の役割 | `international-relations`。つながりの深い国々の暮らしや文化の多様性、違いの尊重、国際交流、国際連合と日本の国際協力を扱う候補。 |

### 今回データに反映した修正

- `jp.elem.social.local-area` の説明に、主な公共施設の「場所」だけでなく「働き」と、古くから残る建造物の分布を加えた。文部科学省解説の第3学年内容 (1) と照らした際、旧説明ではこの範囲が画面上で読み取れにくかったためである。
- 同項目の子ども向け説明と出典メモも更新した。これは候補内容の説明を具体化したもので、公式コード照合済みという意味ではない。
- `jp.elem.social.local-map` の `topicType` を `concept` から `skill` に変更した。地図記号や方位を使うこと自体を、独立した公式内容項目として表すのではなく、地域を調べるための技能として示すためである。
- `jp.elem.social.prefecture-industry` の説明を第4学年内容 (5) に合わせ、伝統的技術を生かす地場産業、国際交流、地域資源の保護・活用を中心に整理した。資源の保護・活用では自然環境か伝統文化のどちらかを選ぶ扱いを残し、文化財・年中行事を受け継ぐ人々に焦点を置く `prefecture-culture` とは区別した。
- 変更した2つの内容説明は `data/social-studies-taxonomy-draft.json` にも反映し、草案と共通データの説明の不一致を解消した。

### 追加で残した確認事項

1. 第6学年の歴史項目は時代別の大枠がある一方、公式解説に示される人物・歴史的事象・文化遺産が各説明でどの程度明示されているかを、項目ごとのチェックリストで確認する。時代名が揃っているだけで網羅済みとは判定しない。
2. `grade-link-121`（`local-area` → `local-map`、関係 `application`）は、関係の向きが「地域を調べるために地図を使う」という説明と整合するか再確認する。今回は関係の向きを推測で変更せず、関係監査の保留事項として記録する。
3. 公式内容への対応候補と、公式コード表のコードとの一致確認は別の作業として残す。社会44件の `reviewStatus` はすべて `needs-review` のまま、公式コードは推測で登録しない。
