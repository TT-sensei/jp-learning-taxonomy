## この表の読み方

ここに記す「第3学年 A(1)」などは、解説に示された学年・内容区分・項目番号を指す。文部科学省の学習指導要領コードそのものではない。項目名は草案との対応を検討するための短い要約であり、公式文の転載ではない。

「対応候補」は公式内容との対応が比較的明確なもの、「分割・修正」は草案の範囲が広い、または複数内容をまとめているもの、「横断」は公式の学年別内容項目ではなく、問題解決の力を見通すプロジェクト独自の整理を示す。candidateGrades はまだ正式配当ではない。

## 3. この第1回レビューで分かったこと

1. 草案45項目のうち、学年別の公式内容項目に比較的直接対応できる候補が多い一方、いくつかは公式項目より広い、または複数の学年の内容をまとめている。
2. 「力と物の動きの基礎」は、現状の名前・説明のままでは対応先が曖昧。第3学年の「風とゴムの力の働き」に改称・再設計するか、独立項目をやめる。
3. 「人の体」「天気と気温」「植物の成長」「水の循環」「自然災害」は、学年別内容と横断概念・取扱い事項を混在させやすいため、分割または関連付けが必要。
4. 第3学年の「物と重さ」「風とゴムの力の働き」、第6学年の「水溶液の性質」など、草案で独立項目として不足している内容がある。既存項目の説明に埋め込まず、独立候補として追加を検討する。
5. 問題解決の力は、比較・関係付け・条件制御・多面的な考察を重点学年の目安として表しつつ、学年横断で使う力として表現するのが適切。

## 4. 次の修正順

1. 「力と物の動きの基礎」を再設計し、第3学年の「風とゴムの力の働き」を不足項目として追加する。
2. 第6学年の「水溶液の性質」を追加し、燃焼・てこ・電気利用と同じ粒度で管理する。
3. 「人の体」を第4学年の運動と第6学年の体の働きに分ける。
4. 「天気と気温」「水の循環」「自然災害」を公式項目と横断概念に分離する。
5. 以上を反映したあと、82V12の公式コード表と照合する。項目番号A(1)等は公式コードと取り違えない。

この文書は学年別内容との**初回の対応レビュー**であり、公式コードの付与や、全候補の最終確定を意味しない。
