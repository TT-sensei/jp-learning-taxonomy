# 算数タクソノミー初回整理監査（2026-10-19）

## この監査の目的

細かな項目を増やすことではなく、学びの大きな流れを見えるようにし、既存項目の重なり・粒度の違い・つながりの弱さ・不足候補を見つける。既存IDは参照互換性のため原則維持し、実際に不足していた学習内容は追加する。

## データの現状

- `topics.json` 全体：274項目
- 算数項目：109件（うち旧親項目として `superseded` の5件を含む）
- 算数の表示対象候補：104件
- `dependencies.json`：176件。整数計算の橋渡し3件と、わり算の筆算に関する関係3件を追加
- 関係タイプは「前提」「先に学ぶと役立つ」「関連する学び」「活用」「発展」が混在している。関係数の多さを、そのまま学びのつながりの強さや正確さとは見なさない。

## 今回見つかった重要な点

### 1. 最優先だった不足：わり算の筆算（項目追加済み）

監査時点では「除法の意味」「あまりのある除法」などがある一方、2位数÷1位数などの筆算を独立して示す有効な項目が見当たらなかった。整数計算の学びの道すじとして大きな欠落だったため、`jp.elem.math.division-algorithm` を追加し、わり算の学びの道すじからも参照できるようにした。

文部科学省の算数編解説では、第4学年で2位数÷1位数の筆算を扱い、既習の除法の計算方法を基に筆算の仕方や確かめ方を考える内容が示されている。参考：<https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf>。また、文部科学省の指導資料にも第4学年「わり算の筆算」の指導例がある：<https://www.mext.go.jp/content/20230809-mxt_kyokoku-000029482_10.pdf>。

対応状況：独立項目を追加し、既習の除法の意味・九九・あまりの意味との関係候補も登録した。公式コードとの対応、練習教材や表現モデルとの接続は引き続き確認する。

### 2. 整数計算から小数計算への橋渡しが弱い

「1位数どうしを中心とした加法・減法」から「2～4桁の加法・減法」、さらに「小数の加法・減法」へと、位をそろえる考え方がどう広がるかを示す関係が不足していた。

今回、次の3件を `dependencies.json` に追加した。いずれも教育的に確認を続ける編集上の候補で、公式の必修順序を意味しない。

- `math-edge-171`：1位数どうしの加法 → 2～4桁の加法・減法
- `math-edge-172`：1位数どうしの減法 → 2～4桁の加法・減法
- `math-edge-173`：2～4桁の加法・減法 → 小数の加法・減法

### 3. 統合候補ではなく「役割を分けて見せる」項目

以下は名前や内容が近いが、今すぐ一つにまとめると意味の違いを失うおそれがある。まず大きな学びのまとまりの中で役割を分けて表示する。

| 項目の組み合わせ | 気になる点 | 当面の扱い |
|---|---|---|
| `estimate-and-check`／`estimate-check-calculation` | どちらも見積もりと確かめを扱う。前者は全学年を横断する考え方、後者は計算に焦点を当てた項目として区別できるか確認が必要 | IDは維持し、横断的な考え方と具体的な計算活用を区別する |
| `unit-conversion-length-area-volume`／`area-units`／`volume-units` | 単位換算の横断項目と、面積・体積それぞれの単位学習が重なって見える | 横断項目は「単位をまたいで考える」、個別項目は「面積・体積の単位」として役割を明記する |
| `data-based-reasoning`／`statistical-viewpoints`／`data-statistical-investigation` | データを根拠に説明する、特徴を多面的に見る、問題を設定して調査する活動の違いが見えにくい | 「調べる→整理・分析する→根拠をもって説明する」の流れで配置し、安易に統合しない |
| `numbers-to-10000`／`numbers-and-place-value` | 大きな数の学びが複数項目に分かれ、学年をまたぐ発展が一覧では見えにくい | 第2学年の1万までの数から、さらに大きな数の位取りへ進む流れとして見せる |
| `decimals-tenths`／`decimal-place-value`／`decimal-fraction-tenths` | 小数の意味・位取り・0.1と1/10の関係が近接している | 「小数の意味→位取り→分数との関係」として段階を明示し、重複かどうかは内容を照合して判断する |

### 4. 項目数より、関係の意味を見直す

関係データは「関連する学び」が多く、これが学習順序の矢印として読まれると誤解を招く。マップでは、少なくとも次の意味を視覚的にも言葉でも分ける必要がある。

- 先に理解しておくとよいこと
- 似ている・比べられる学び
- 既に学んだことを使う場面
- さらに広げる学び

関係のない項目を見かけ上つなぐより、つながりが未確認であることを残す方針を維持する。

### 5. 粒度の違いは、一覧の表示階層で吸収する

算数の項目には、単元に近いまとまり、個別の技能、学年を横断する考え方が同じ一覧に並んでいる。すべてを同じ大きさのカードで表示すると、細かすぎる・散らばっている印象になる。

今後は次の3層を基本とする。

1. **大きな学びのまとまり**：最初に見る道すじ
2. **詳しい学習項目**：必要なときに開く
3. **確認問題・つまずき・練習**：別データで管理し、タクソノミーの項目を増やす理由にしない
