# 学習指導要領コードとの対応付け

## 公式参照元

- 文部科学省「文部科学省 教育データ標準」  
  https://www.mext.go.jp/a_menu/other/data_00001.htm
- 文部科学省「学習指導要領コードのコード表（全体版）」  
  https://www.mext.go.jp/a_menu/other/data_00002.htm

小学校算数の対応付けには、平成29年告示版の最新版として掲載されている 82V12（バージョン1.2、2022年3月14日公表）を使う。

## 対応付けのルール

1. 公式コード表の教科・学年・内容の記述を確認する。
2. 学習項目と対応する公式コードを照合し、コードそのものを推測して作らない。
3. 一つの学習項目が複数のコードにまたがる場合は、確認できたすべてのコードを登録する。
4. 公式コードの記述と学習項目が完全一致しない場合は、無理に対応付けず、関係を説明する注記を付ける。
5. 「前提関係」はプロジェクト独自の教育的整理であり、公式コードから自動的に導かれるものではない。
6. コード表の版を変更した場合は、旧版の対応を上書きせず、版情報を記録する。

## ステータス

- `not-checked`: 未照合
- `candidate`: 対応候補。人による確認が必要
- `verified`: 公式コードと記述を照合済み
- `no-direct-match`: 直接対応するコードが見つからない

## 対応表

[`data/curriculum-code-mapping.json`](../data/curriculum-code-mapping.json) にプロジェクト独自の学習項目IDと公式コードの対応を記録する。現在は全項目が `not-checked` であり、公式コードとの対応が完了したという意味ではない。
