# 子ども向け表示の見直し（2026-10-18）

## 今回の変更

学習マップで「何を学ぶのか」が項目名から分かるよう、子ども向けの表示名と説明を追加した。

- 内部の整理名 `name`、学習項目ID、教科、領域、出典、関係データは維持する。
- 画面表示には `studentName` と `studentDescription` を使う。
- 名前は、難しい分類語だけでなく「何を考える・調べる・使う学びか」が伝わる言葉に言い換える。
- 説明は、学習の対象や活動が分かる短い文を基本にする。
- 関係データ170件すべてに `studentRationale` を追加し、関係の理由も子ども向けの文にする。元の `rationale` と関係の種類は維持する。
- 教科の領域名も、子どもが読み取れる短い見出しに置き換える。内部データの領域名は変更しない。
- 関係の説明では「加法・減法」などの用語を、必要に応じて「たし算・ひき算」などの言葉に言い換える。
- 学習項目IDや関係の参照先は変更していない。

## 表示名の例

| 教科 | 整理用の名前 | 子ども向けの表示 |
|---|---|---|
| 国語 | 音読・朗読で表現を味わう | 声や間を工夫して音読しよう |
| 算数 | 1位数どうしを中心とした加法 | くり上がりのあるたし算 |
| 算数 | 乗法の意味 | かけ算になる場面を考えよう |
| 社会 | 戦国の世の統一 | 戦国時代から全国統一へ |
| 理科 | 電気の通り道と回路 | 電気が流れる道すじ（回路） |

## 一括更新後の機械的な確認

- 学習項目データ：273件（うち表示対象268件、旧項目5件）
- 表示対象268件すべてに `studentName` と `studentDescription` があることを確認。
- 学習項目IDの重複なし。
- 関係データ170件すべてに子ども向けの説明があり、参照先切れなし。
- 学習項目の既存ID、内部名称、学年候補、出典ID、関係IDは維持。

## 追加した改善

- 社会の一覧・学年マップでは、学年名だけで並べず、「地域のようす」「くらしを支えるしくみ」「都道府県のようす」「日本の国土と自然」「産業と環境」「歴史のうつりかわり」「政治と世界」「資料を使って調べる」に分けて表示する。
- 検索でも、子ども向けの項目名・説明・内容のまとまりを対象にする。
- 更新後の機械確認で、表示対象268件すべてに項目名・説明があり、170件すべてに関係説明があること、表示名の教科内重複がないこと、関係データの参照切れがないこと、厳密な前提関係と `prerequisiteIds` が一致していることを確認した。

## 引き続き必要な確認

これは表示文言の初回一括改善であり、教科内容すべての教育的妥当性を個別に確定したものではない。特に、学年配当の候補や学習項目間の関係は引き続き確認が必要。言い換えによって学習内容の意味が変わっていないか、児童が実際に見たときに誤解しないかを、教科ごとに少しずつ見直す。
