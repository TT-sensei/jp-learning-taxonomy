# 国語タクソノミー 初期レビュー記録

更新日：2026-10-18  
対象：共通データ `data/topics.json` の国語75項目と、統合前の分類設計・レビュー経緯

## この記録の目的

学習項目を増やすだけでなく、公式の内容構成に沿っているか、似た項目が別々に立っていないか、学年配当を推測で固定していないかを、段階的に確認する。ここに記す重なりは現時点の「レビュー候補」であり、統合を確定したものではない。

## 公式の内容構成との対応

| 草案の領域 | 対応させる公式の内容構成 | 確認ポイント |
|---|---|---|
| 言葉の特徴や使い方に関する事項 | 知識及び技能（1） | 語彙、文や文章、表記、言葉の働きの区分を細かくしすぎていないか |
| 情報の扱い方に関する事項 | 知識及び技能（2） | 情報どうしの関係と、情報を集めたり伝えたりする活動を混同していないか |
| 我が国の言語文化に関する事項 | 知識及び技能（3） | 伝統的な言語文化、文字・書写、読書を区別しつつ関係付けられているか |
| 話すこと・聞くこと | 思考力、判断力、表現力等 A | 話す／聞く／話し合う／準備する過程が適切に整理されているか |
| 書くこと | 思考力、判断力、表現力等 B | 題材、構成、記述、推敲、共有の過程を見通せるか |
| 読むこと | 思考力、判断力、表現力等 C | 内容把握、精査・解釈、考えの形成、共有が混ざりすぎていないか |

これは公式構成との対応先を示すための整理であり、個々の項目が公式記述と照合済みであることや、公式コードが付与されていることを意味しない。根拠資料は文部科学省「小学校学習指導要領（平成29年告示）解説 国語編」とする。

| 聞くこと・話合い | 大事なことを聞く／質問して確かめる／異なる意見を比べて聞く／相手の考えを整理して伝え返す／話し合い考えをまとめる | 聞き取る、質問する、応答する、合意形成を区別する。単に「話合い」にまとめて個別の技能を失わないようにする。 |

| 要約・引用・根拠 | 要約・言い換え／引用と出典を明らかにして書く／言葉や文を根拠にして説明する／筆者の主張と根拠を捉える | 読む際に根拠を選ぶ力と、書く際に引用・出典を示す力を分ける。要約は読む・書くの双方に現れるため、共通概念か領域別技能かを判断する。 |
| 読むことの内容理解・解釈 | 中心となる内容や要旨／段落や文章全体の構成／事実と意見、理由と例／筆者の主張と根拠／叙述を結び付けて意図を考える | 内容・構成の把握、主張と根拠の関係、叙述からの推論、表現効果を区別する。説明文と物語文で共通する観点／異なる観点を確認する。 |
| 複数資料・複数文章 | 文章・図表・写真を関連付ける／複数の文章を比べる／複数資料の情報を照合する | 「表現形式を横断して読む」「文章同士を比較する」「情報の正確さを照合する」の違いを明記し、目的が同じ項目は統合を検討する。 |

## 学年配当を確認するときのルール

- 「低・中・高学年」の帯は、一覧を見通すための仮ラベルとして扱う。
- 公式解説の〔第1学年及び第2学年〕〔第3学年及び第4学年〕〔第5学年及び第6学年〕の記述を確認し、初出学年帯と継続して扱う学年帯を分けて記録する。
- 公式文書に明示されていない個別学年を、教科書の掲載学年だけで公式配当として扱わない。
- 教材名・単元名ではなく、育成する知識・技能や思考・判断・表現を記録する。
- 公式コードは、コード表と実際に照合できるまで登録しない。

## 草案ファイルの整理（2026-10-21）

このレビュー記録は、統合前の分類設計・公式資料との照合・修正判断を追跡するために残す。学習項目そのものは共通データ `data/topics.json` に統合されているため、別管理の教科別 JSON 草案は現行データの二重管理を避ける目的で整理対象とした。過去の候補学年や記述を現行の確定情報として再利用せず、現在の項目・学年配当は共通データとコード対応表で確認する。


## 項目数の整理と統合（2026-10-24）

「項目数を維持すること」より、子どもや先生が学習のまとまりを理解しやすいことを優先し、重なりが大きい6組を統合した。統合元IDは削除せず `topicLifecycle: superseded` と `replacementTopicIds` を設定し、参照の移行先を残した。

- 「言葉の意味や使い方」＋「語彙を広げ、使い分ける」
- 「仮名遣いと表記のきまり」＋「句読点や表記のきまり」
- 「文の組み立てを捉える」＋「接続語や修飾語の働き」
- 「情報を比べ、分類する」＋「情報のまとまりと構造」
- 「叙述を基に想像し、推論する」＋「叙述を結び付けて人物や筆者の意図を考える」
- 「複数の文章を比べて読む」＋「複数資料の情報を照合する」

国語の表示対象は75項目から69項目になった。統合した内容は後継項目の説明に取り込み、学年範囲も統合元を含めて広げた。依存関係の参照先と公式コード対応表の項目参照も後継IDへ移行した。旧IDは互換性と履歴のためデータ内に保持している。

これは「似ているから一つにした」というだけではなく、子どもが学ぶ力として同じまとまりにできるかを基準にした編集上の統合である。読む・書くなど異なる活動領域の技能は、重複があっても無理に統合しない。統合後の学年配当と公式記述との対応は未確定のため、引き続き確認する。

### 項目の不足・重複について

- 音読・朗読と詩歌の響き・リズムは、前者を音声化する技能、後者を伝統的な詩歌の言葉・調子を味わう学習として分ける。
- 昔話・神話・伝承と言葉遊び、短歌・俳句、古文・漢文等は、学年段階の異なる伝統的言語文化として区別する。
- 書写は文字を整えて書く技能、原稿用紙等の書式は文章作成時の実用的な形式知識として区別する。
- 読書習慣と図書館・資料の探し方は、読書に親しむことと、目的に応じて資料へアクセスする方法として区別する。
- 作品・作者について知る項目は削除せず、公式の独立指導事項ではない発展的な読書活動であることを明示した。
