# 国語タクソノミー 初期レビュー記録

更新日：2026-10-18  
対象：共通データ `data/topics.json` の国語75項目と、統合前の分類設計・レビュー経緯

## この記録の目的

学習項目を増やすだけでなく、公式の内容構成に沿っているか、似た項目が別々に立っていないか、学年配当を推測で固定していないかを、段階的に確認する。ここに記す重なりは現時点の「レビュー候補」であり、統合を確定したものではない。

## 公式の内容構成との対応

| 草案の領域 | 対応させる公式の内容構成 | 確認ポイント |
|---|---|---|
| 言葉の特徴や使い方に関する事項 | 知識及び技能（1） | 語彙、文や文章、表記、言葉の働きの区分を細かくしすぎていないか |
| 情報の扱い方に関する事項 | 知識及び技能（2） | 情報どうしの関係と、情報を集めたり伝えたりする活動を混同していないか |
| 我が国の言語文化に関する事項 | 知識及び技能（3） | 伝統的な言語文化、文字・書写、読書を区別しつつ関係付けられているか |
| 話すこと・聞くこと | 思考力、判断力、表現力等 A | 話す／聞く／話し合う／準備する過程が適切に整理されているか |
| 書くこと | 思考力、判断力、表現力等 B | 題材、構成、記述、推敲、共有の過程を見通せるか |
| 読むこと | 思考力、判断力、表現力等 C | 内容把握、精査・解釈、考えの形成、共有が混ざりすぎていないか |

これは公式構成との対応先を示すための整理であり、個々の項目が公式記述と照合済みであることや、公式コードが付与されていることを意味しない。根拠資料は文部科学省「小学校学習指導要領（平成29年告示）解説 国語編」とする。

## 学年配当を確認するときのルール

- 「低・中・高学年」の帯は、一覧を見通すための仮ラベルとして扱う。
- 公式解説の〔第1学年及び第2学年〕〔第3学年及び第4学年〕〔第5学年及び第6学年〕の記述を確認し、初出学年帯と継続して扱う学年帯を分けて記録する。
- 公式文書に明示されていない個別学年を、教科書の掲載学年だけで公式配当として扱わない。
- 教材名・単元名ではなく、育成する知識・技能や思考・判断・表現を記録する。
- 公式コードは、コード表と実際に照合できるまで登録しない。

## 項目数の整理と統合（2026-10-24）

「項目数を維持すること」より、子どもや先生が学習のまとまりを理解しやすいことを優先し、重なりが大きい6組を統合した。統合元IDは削除せず `topicLifecycle: superseded` と `replacementTopicIds` を設定し、参照の移行先を残した。

- 「言葉の意味や使い方」＋「語彙を広げ、使い分ける」
- 「仮名遣いと表記のきまり」＋「句読点や表記のきまり」
- 「文の組み立てを捉える」＋「接続語や修飾語の働き」
- 「情報を比べ、分類する」＋「情報のまとまりと構造」
- 「叙述を基に想像し、推論する」＋「叙述を結び付けて人物や筆者の意図を考える」
- 「複数の文章を比べて読む」＋「複数資料の情報を照合する」

国語の表示対象は75項目から69項目になった。統合した内容は後継項目の説明に取り込み、学年範囲も統合元を含めて広げた。依存関係の参照先と公式コード対応表の項目参照も後継IDへ移行した。旧IDは互換性と履歴のためデータ内に保持している。

これは「似ているから一つにした」というだけではなく、子どもが学ぶ力として同じまとまりにできるかを基準にした編集上の統合である。読む・書くなど異なる活動領域の技能は、重複があっても無理に統合しない。統合後の学年配当と公式記述との対応は未確定のため、引き続き確認する。

### 項目の不足・重複について

- 音読・朗読と詩歌の響き・リズムは、前者を音声化する技能、後者を伝統的な詩歌の言葉・調子を味わう学習として分ける。
- 昔話・神話・伝承と言葉遊び、短歌・俳句、古文・漢文等は、学年段階の異なる伝統的言語文化として区別する。
- 書写は文字を整えて書く技能、原稿用紙等の書式は文章作成時の実用的な形式知識として区別する。
- 読書習慣と図書館・資料の探し方は、読書に親しむことと、目的に応じて資料へアクセスする方法として区別する。
- 作品・作者について知る項目は削除せず、公式の独立指導事項ではない発展的な読書活動であることを明示した。

## 2026-11-08 第2領域の公式内容照合・再整理

対象：国語「言葉の特徴や使い方に関する事項」。現行16項目と統合済み3項目を確認し、文部科学省「小学校学習指導要領解説 国語編」の学年段階に照合した。公式の記述にある学年帯（第1・2学年、第3・4学年、第5・6学年）を基準にし、個別学年の公式配当を推測しない。

### 追加した項目

- 「話し言葉と書き言葉の違い」：第5・6学年の特徴の違いへの気付き。
- 「時代や世代による言葉の変化」：第5・6学年の時間経過・世代差。
- 「比喩や反復など表現の工夫」：第5・6学年の表現の工夫への気付き。
- 「言葉がもつ働き」：第5・6学年の相手の行動を促す働き。

### 既存項目の主な修正

- 音読・朗読：低学年の語のまとまり、中学年の文章全体、高学年の作品の特徴を生かした朗読という発展を明確化。
- 仮名・漢字：学年別漢字配当表に沿った読み書きと、高学年の仮名・漢字の由来や特質を追記。
- 音や文字：音節と文字の関係、アクセントによる意味の違いを明記。
- 表記：長音・拗音・促音・撥音、助詞「は・へ・を」、句読点・かぎかっこ、送り仮名・仮名遣い、段落・会話部分の改行を学年段階に沿って整理。
- 語彙：低学年の身近な語句、中学年の類別・類義語・対義語、高学年の抽象語・同音異義語・多義語へ発展を具体化。
- 辞書：第3・4学年で使い方を理解し、調べる習慣を付ける段階を初出候補に整理。
- 言葉遣い：低・中学年の丁寧な言葉と普通の言葉、相手・目的に応じた表現と、高学年の敬語を分離。
- 文の構成：低学年の主語・述語、中学年の修飾・被修飾・指示語・接続語、高学年の文の成分の順序・照応へ発展。
- ことわざ・慣用句・故事成語：公式の初出学年帯である第3・4学年に整理。
- 言葉の種類・活用：中学年の語句の類別と、高学年の単語の活用・助詞・助動詞を一つの発展線として整理。
- 語句の構成・由来・関係：高学年の内容として整理し、文法的な文のつながりとは区別。

### 重複・補助項目の扱い

- 「文の種類と文末表現」は、公式の独立事項名ではないことを明記し、低学年の文づくりを支える編集上の補助項目として維持。
- 「擬音語・擬態語などの表現」は、公式の独立事項として断定せず、語彙を豊かにする具体例として扱う。
- 「場面に応じた言葉遣い」と「敬語」は、前者を低・中学年の言葉の選択、後者を高学年の敬語の働きとして分ける。
- 「文の組み立て」と「言葉の種類・活用」は、文全体の関係と単語の性質・働きという観点で役割を分ける。

- 第1・2学年：共通、相違、事柄の順序など、情報と情報との関係。
- 第3・4学年：考えと理由・事例、全体と中心の関係。情報整理として比較・分類、必要な語句の書き留め、引用と出典表示、辞書・事典の使い方。
- 第5・6学年：原因と結果など情報と情報との関係。情報どうしの関係付け、図などによる語句と語句との関係の表し方。

### 既存項目の整理

- 「情報を比べ、整理する」：第3・4学年の比較・分類に焦点化。
- 「原因と結果などの関係」：第5・6学年に整理。
- 「図表や引用を使って情報を示す」：公式の中学年事項に合わせ、「引用の仕方と出典の示し方」に改題。図表による関係図示は高学年項目へ分離。
- 「辞書などを使って言葉を調べる」：言葉の特徴や使い方の領域から本領域へ移動。第3・4学年に整理。
- 「情報を集め、記録する」：各領域の言語活動を支える横断的な補助項目であり、公式の独立事項ではないことを明記。
- 「事実・意見・解釈を区別する」「情報の出どころと信頼性」「文章・図表・写真などを関連付ける」：有用な発展・補助項目として維持するが、小学校学習指導要領の当該事項に独立して列挙された指導事項ではないことを明記。

### 追加した項目

- 「共通点・相違点・順序の関係」：第1・2学年。

- 「必要な語句を書き留める」：第3・4学年。

## 2026-11-08 国語「読むこと」の公式内容照合・再整理

対象：国語「読むこと」16項目。文部科学省「小学校学習指導要領解説 国語編」第2章C「読むこと」の構成と、第3章の第1・2学年、第3・4学年、第5・6学年の指導事項・言語活動例を照合した。

### 公式の学習過程

- 構造と内容の把握：叙述を基に、文章の構成・展開と内容を捉える。
- 精査・解釈：重要な語や文を選ぶ、要約する、人物の行動・気持ち・情景を具体的に想像する、文章と図表を結び付ける、論の進め方や表現の効果を考える。
- 考えの形成：読んで理解したことを、既有の知識や体験と結び付けて感想・考えにする。
- 共有：読んで形成した考えを表現し、互いの考えを共有して自分の考えを広げる。
- これらは学習過程を整理したもので、必ずしも一方向の固定順序を意味しない。

### 学年段階に沿った整理

- 第1・2学年：時間的・事柄の順序、場面・登場人物の行動から内容の大体を捉える。重要な語や文を選び、場面から行動を具体的に想像する。自分の体験と結び付けて感想をもち、共有する。
- 第3・4学年：段落相互の関係、考えと理由・事例の関係を叙述から捉える。中心となる語や文を見付けて要約し、登場人物の気持ちの変化・性格・情景を場面の移り変わりと結び付けて想像する。理解したことに基づいて感想や考えをもつ。
- 第5・6学年：事実と感想・意見の関係、文章全体の構成と要旨を捉える。文章と図表などを関連付けて必要な情報を見付け、論の進め方を考える。人物像や物語の全体像、表現の効果を考え、自分の考えをまとめる。

### 既存項目の主な修正

- 「出来事や場面の順序」：低学年の説明的文章・文学的文章の内容把握に焦点化。
- 「中心となる内容や要旨」：低・中・高学年の発展を明記し、低学年の内容の大体から高学年の要旨把握へつなげた。
- 「登場人物や場面、心情」：行動・気持ち・相互関係の発展を学年段階に沿って明確化。
- 「読んで考えたことを交流」：体験との結び付き、理解に基づく感想・考え、自分の考えのまとめと共有を段階化。
- 「事実と意見、理由と例」：中学年の考えと理由・事例、高学年の事実と感想・意見を区別。
- 「段落や文章全体の構成」：中学年の段落相互の関係、高学年の文章全体の構成・要旨に整理。
- 「筆者の主張と根拠」：高学年の説明的文章に焦点化。
- 「表現の工夫と効果」：高学年の文学的文章における表現の効果を中心に整理。
- 「叙述を根拠にして説明」：読む際に根拠となる叙述を見付けることに焦点化し、引用の形式・出典表示とは区別。
- 「図書館や資料」：低学年の本の選択、中学年の事典・図鑑、高学年の複数の本・新聞の活用へ発展を整理。

### 発展的・補助的な項目の扱い

- 「目的に応じて読み方を工夫」「作品や作者について知る」「語り手や視点」「文章の種類や目的」「複数の文章・資料を比べる」は、読む活動を広げる上で有用だが、独立した公式指導事項とは区別して補助・発展項目として扱う。
- 「複数の文章を比較する」は高学年の言語活動例に位置付け、独立した必須指導事項としては扱わない。
- 「叙述を根拠にして考えを説明する」は読む際の根拠選択として扱い、引用・出典の書き方は「情報の扱い方」や「書くこと」と区別する。
- 音読・朗読は「言葉の特徴や使い方に関する事項」に位置付くため、読むことの学びの道すじから外し、領域を混同しないようにした。
- 読書習慣は「我が国の言語文化に関する事項」に位置付くため、読書活動との接続として道すじに残すが、「読むこと」の独立指導事項とは区別する。

### 件数・確認状態

- 「読むこと」の表示対象は16項目を維持。重複を避けながら、既存項目の説明・学年段階・補助項目の位置付けを更新した。
- 公式の学年帯を参照した編集上の候補であり、個別学年の公式配当を断定しない。
- 発展・補助項目には公式コードを割り当てず、独立した公式事項と誤認されないよう対応表を整理した。
- 対象項目の reviewStatus は needs-review のまま。コードの意味的な対応付けは別途確認が必要。

## 2026-11-08 国語「話すこと・聞くこと」の公式内容照合・再整理

対象：既存12項目を見直し、共通する公式指導事項「話題の設定、情報の収集、内容の検討」を新設して計13項目とした。文部科学省「小学校学習指導要領解説 国語編」第2章Aおよび第3章各学年段階を参照した。

### 公式の学習過程

- 話題の設定、情報の収集、内容の検討：話す・聞く・話し合うことに共通する過程。話題を決め、目的に合う材料を選び、整理する。
- 構成の検討、考えの形成（話すこと）：伝えたい内容の順序や構成を考える。
- 表現、共有（話すこと）：相手や場面、資料の活用などを通して伝え方を工夫する。
- 構造と内容の把握、精査・解釈、考えの形成、共有（聞くこと）：話の内容を捉え、話し手の意図や自分の聞く目的に応じて考える。
- 話合いの進め方の検討、考えの形成、共有（話し合うこと）：目的や進め方、立場や意図を踏まえて考えを広げたりまとめたりする。
- 学習過程は固定された授業順序ではなく、各指導事項は相互に関連する。

### 学年段階に沿った整理

- 第1・2学年：身近なことや経験から話題を決めて必要な事柄を選ぶ。経験や行動の順序を考えて話し、相手や伝えたい事柄に応じて声の大きさ・速さを工夫する。話し手の知らせたいことや自分の聞きたいことを落とさずに聞き、感想をもつ。相手の発言を受けて話をつなぐ。
- 第3・4学年：目的を意識して話題を決め、材料を比較・分類して必要な事柄を選ぶ。理由や事例を挙げて話の中心が明確になる構成を考える。話の中心や場面に応じて抑揚・強弱・間を工夫する。必要なことを記録・質問しながら聞き、話の中心を捉えて自分の考えをもつ。目的や進め方を確認し、司会などの役割を果たして共通点・相違点に着目し、考えをまとめる。
- 第5・6学年：目的や意図に応じて材料を分類・関連付け、伝え合う内容を検討する。事実と感想・意見を区別して話を構成し、資料を活用して表現を工夫する。話し手の目的や自分の聞く意図に応じて聞き、話し手の考えと比較して自分の考えをまとめる。互いの立場や意図を明確にして計画的に話し合い、考えを広げたりまとめたりする。

### 既存項目の主な修正

- 「経験や出来事を順序立てて話す」：低学年の話題選択と順序構成に焦点化。
- 「話す内容を選び、構成を考える」：学年帯に沿って材料選択・比較分類・関連付け、理由事例、事実感想意見の構成へ発展。
- 「発表する」：低学年の声量・速さ、中学年の抑揚・強弱・間、高学年の資料活用へ整理。
- 「大事なことを落とさずに聞く」：低学年の聞くことエに焦点化。
- 「聞きながら要点をメモする」：中学年の記録・質問・中心把握に焦点化。
- 「異なる意見を比べて聞く」：高学年の話し手の考えと比較し、自分の考えをまとめることに焦点化。
- 「事例や資料を用いて説明する」：中学年の理由・事例を挙げて話の中心を明確にすることに焦点化。
- 「理由や根拠を明確にして話す」：高学年の事実・感想・意見を区別した話の構成に焦点化。
- 「話し合い、考えをまとめる」：低学年の発言をつなぐ、中学年の司会・共通点相違点、高学年の立場・意図を明確にした計画的な話合いに再整理。

### 発展的・補助的な項目の扱い

- 「質問や応答」「相手の発言を整理して伝え返す」「インタビュー」は、公式指導事項を支える技能・言語活動として扱い、独立した公式指導事項とは区別する。
- インタビューは中学年・高学年の言語活動例に位置付け、単独の必須指導事項としては扱わない。

- 公式の学年帯を参照した編集上の候補であり、個別学年の公式配当を断定しない。公式コードの意味的な照合は未実施のため、新設項目と補助項目にコードを推測で割り当てない。
