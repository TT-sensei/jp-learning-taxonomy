# 算数全体の学びの見取り図

更新日：2026-10-19

## ねらい

細かな学習項目を一覧で追う前に、算数全体の大きなまとまりと、領域をこえたつながりをつかめる入口を用意する。

## 大きなまとまり

- 数と計算
- 図形
- 量と測定
- 変化と関係
- データの活用
- 学びを横断して使う（表現、説明、問題解決、見積もり、確かめ）

最初の5つは算数の内容領域をもとにした大きなまとまり、最後の1つは領域をこえて使う考え方を示す。公式の領域とプロジェクト独自の横断的観点を同列の公式分類として扱わない。

## 設計方針

- 最初の画面では大きなまとまりと短い流れだけを見せる。
- 詳しい学習項目は折りたたみ、既存 topic ID へのリンクとして参照する。
- 一つの学習が複数の場面で役立つことを認め、一本道の順序に固定しない。
- 学年配当や関係は確認中の候補として扱う。
- つまずき診断・復習プリントは学習項目の分類と分けて設計する。
