# 算数データのカバレッジ確認メモ

更新日：2026-10-18  
対象：小学校算数の試作データ（版 0.3.0-draft）

## 目的

現在の項目一覧を完成版と誤認しないよう、学習指導要領との照合前に見つかった粒度の粗さ・不足候補を記録する。以下は正式なカリキュラム対応表ではなく、次回レビューのための編集メモである。

## 今回追加した候補

- □などを使った未知数を含む式
- 小数・分数・整数の相互関係
- 計算のきまりと計算方法の工夫
- 角の測定と作図
- 垂直・平行な直線や図形の作図
- 立体の見取図・展開図
- 体積の単位
- 比例を表・式・グラフで表す
- 比の値と等しい比
- データの分布の整理
- 統計的な問題解決
- 量を横断する単位換算

これらは項目を分けて検討するための候補であり、学年配当や用語は公式資料との照合が必要。すべて `needs-review` のままとする。

## 次の確認項目

1. 学習指導要領コード 82V12 の算数コードと各項目を対応付ける。公式コードは文部科学省の教育データ標準ページを参照する。
2. 学年配当を、領域・内容のまとまり・指導事項に照らして確認する。
3. 「面積」「体積」「測定」の分類と、領域をまたぐ単位換算の分類が二重計上にならないか確認する。
4. 前提関係は、厳密な前提と、教員の判断による関連・発展を区別する。
5. 統計的な内容では、データの収集・整理・分析・解釈・結論の検討が抜けていないか確認する。
6. 教科書の配列を唯一の順序とせず、複数の学び方を許容する関係データにする。

このメモとデータは、文部科学省の承認・公式解釈を示すものではない。公式コードとの対応が確認されるまでは、プロジェクト独自の整理案として扱う。

## 2026-10-18 追加レビュー

東京書籍の公開資料で小学5・6年の単元一覧と指導例を確認し、初期データに不足していた次の項目を追加した。

- 文字を用いた式（「□を使った式」と区別）
- 合同な図形
- およその面積と体積
- 並べ方と組み合わせ方

データは学習項目93件・関係65件になった。追加項目と出版社資料の対応はプロジェクト独自の草案であり、文部科学省の公式コード表との照合は未完了。今後は公式コード表、啓林館の内容系統一覧表、東京書籍の線分図・数直線の系統表を実際に照合し、学年範囲と項目の粒度を見直す。

追加確認として、東京書籍の小学5年の単元一覧から「図形の角」「変わり方調べ」も独立した項目として見直す必要があることを確認し、「三角形や四角形の角の性質」「二つの数量の変わり方」を追加した。現時点のデータは学習項目95件・関係67件。いずれも公式コードとの照合は未完了。
