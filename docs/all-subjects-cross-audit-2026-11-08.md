# 全教科横断・一次監査記録（2026-11-08）

## 1. 監査の位置付け

対象は `data/topics.json` の全14教科等・現行364項目。文部科学省が公開する小学校学習指導要領解説（平成29年告示）を基準に、収録範囲、学年範囲、学年間の発展、出典・コード対応、学習項目間の関係、データ整合性を横断して確認した。

今回の監査は、全項目の教育的妥当性を最終承認するものではない。項目の説明や学習目標が存在することと、公式内容・学年配当・学習順序との意味的な対応が確認済みであることは分けて扱う。未確認の項目や関係を確認済みに変更していない。

- 学習項目・関係・学びの道すじ・出典・領域参照・表現モデル・コード対応表のID重複：なし
- 学習目標、説明、子ども向け表示、根拠出典の欠落：なし
- 学習関係449件の参照切れ・自己参照・重複：なし
- 前提関係の循環：なし
- 学習項目の前提IDと関係データの不一致：なし
- 学びの道すじ57本、表現モデル19件、コード対応表376件の参照切れ：なし
- マニフェストの収録数、教科別・学年別・領域別の件数：一致
- コード形式・対応状態の整合性：エラーなし

この結果はデータ構造と参照の検証であり、内容の正しさを自動的に保証するものではない。また、GitHub Actions上で `validate.mjs` を実行した結果ではなく、取得データを使って検証条件を再計算した結果である。

## 5. 学年間のつながり

現時点で `gradeBandProgression` を持つ項目は42件で、内訳は社会7、理科4、音楽9、図画工作10、体育12。これらは学年段階の違いを詳細画面で示すための基礎になっている。

一方、生活・家庭・外国語活動・外国語・道徳・総合的な学習の時間・特別活動には、項目ごとの段階別説明がまだない。国語・算数にも同形式の段階別説明はなく、文章による説明や学年配当候補で表している。すべての教科に同じ形式を機械的に追加するのではなく、教科の性質に応じて「学年別の内容」「2学年のまとまり」「全学年で繰り返し深める力」を分けて示す必要がある。

特に、次の点を重点確認する。

- 生活科：1・2年を一体として扱いながら、活動・体験の質がどのように深まるか。
- 家庭科：5・6年で扱う内容と、生活課題の発見から実践・評価・改善への流れ。
- 外国語活動・外国語：3・4年の体験的な聞く・話す活動と、5・6年の読む・書くを含むコミュニケーションの接続。
- 道徳：内容項目ごとの対象学年段階を保ち、全学年で一律に同じ内容を扱うように見せない。
- 総合・特別活動：学校や地域の実態に応じる内容と、学習過程・活動の共通の枠組みを分ける。

## 6. 学習関係・公式コードの状態

学習関係は449件。参照整合性は保たれているが、449件すべてが `needs-review` であり、前提・推奨する前提・関連・活用・発展の教育的妥当性は未承認である。特に「前提」は、公式資料が一律の順序を定めているかのように見えないよう、根拠と表示を確認する。

学習指導要領コード対応表は376項目分あり、状態の内訳は次のとおり。

- verified：27
- candidate：211
- no-direct-match：31
- not-checked：107

コードの存在確認と、学習項目の意味が公式記述に対応することは別である。候補コードを確定コードとして表示せず、横断項目や複数内容をまとめた項目は、無理に一対一対応させない。

現行364項目の `reviewStatus` はすべて `needs-review`。算数の一部に学年配当の確認済み記録があるが、これは項目全体の最終承認とは別である。学習関係も全件レビュー待ちであるため、現時点で全教科を「確認済み」「完成」と表示しない。

## 7. 次の監査順

1. 算数73項目の候補学年を公式解説に照合する。特に図形・測定・変化と関係・データの活用を優先する。
2. 生活・家庭・外国語活動・外国語・道徳・総合・特別活動の学年段階を、教科の性質に合った形で補う。
3. 音楽・図画工作・体育の既存の段階別説明を、公式解説の内容区分と照合し、重複・不足を確認する。
4. 国語・社会・理科の学年配当候補を、説明の点検とは別に最終確認する。
5. 449件の学習関係をタイプ別にレビューし、前提関係の根拠と学年順序を確認する。
6. 公式コードの意味的な対応を継続し、未確認・候補を明示する。
7. GitHub Pages反映後、PC・タブレット・スマートフォンで一覧・検索・詳細・学年表示を実機確認する。
