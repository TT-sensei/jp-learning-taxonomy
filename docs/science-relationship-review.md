# 理科タクソノミー：項目間の関係候補

更新日：2026-10-20

## 目的と扱い

48項目を単なる一覧で終わらせず、既習事項を使って新しい内容を理解したり、別の単元に学びをつないだりできるよう、項目間の関係候補を整理する。

この文書は**関係の設計候補**であり、確定した前提条件や公式の系統表ではない。実際の学年配当、教科書の構成、各項目の説明を照合してからデータ化する。ここでいう「前提」は、学習指導要領上の必須前提を意味せず、学習設計上の関連候補を指す。

## 関係の種類

- **学習上のつながり**：後の学習を考える際に活用できる知識・見方
- **概念の橋渡し**：異なる単元に共通する見方や概念
- **観察・探究の方法**：複数の単元で共通して用いる問題解決の力
- **同一公式項目内の細分化**：プロジェクト側で細かく分けた候補同士の関係

## 1. 学習上のつながり候補

| 先に学ぶ・活用する候補 | つながる候補 | 関係の種類 | 確認ポイント |
|---|---|---|---|
| 物の形・体積と重さ（現行ID: `matter`） | 物の溶け方 | 概念の橋渡し | 物の性質を比較し、量や条件に着目する見方を活用できるか。公式内容の粒度を確認する。 |
| 空気と水の性質（現行ID: `air-properties`） | 金属・水・空気と温度 | 学習上のつながり | 空気や水の性質を、温度変化に伴う体積・状態の変化と混同せずにつなぐ。 |
| 電気の通り道と回路 | 電気の働き | 学習上のつながり | 回路の成立と、電流による働きの学習を区別して関係付ける。 |
| 電気の働き | 電気の利用と変換 | 学習上のつながり | 乾電池・光電池等の働きと、発電・蓄電・エネルギー変換の扱いを分けて確認する。 |
| 磁石の性質 | 電流がつくる磁力 | 概念の橋渡し | 磁石と電磁石の共通点・違いを比較する。 |
| 身近な生物の体のつくりと成長 | 季節と生物の変化 | 概念の橋渡し | 生物の構造・成長と、季節による活動・変化を分けて整理する。 |
| 植物の発芽・成長・結実 | 植物と日光・養分 | 学習上のつながり | 成長条件と養分のつくられ方を同じ内容として扱わず、発展関係を確認する。 |
| 動物の誕生と成長 | 人の体のつくりと働き | 概念の橋渡し | 動物の誕生と、人の体の器官の働きを直接の前提とはせず、生命の共通性を考える関連として扱う。 |
| 天気の様子 | 天気の変化と雲 | 学習上のつながり | 気温・雲・天気の変化と気象情報の活用を整理する。 |
| 雨水の行方と地面の様子 | 流れる水の働きと土地の変化 | 概念の橋渡し | 地表の水の動きと、流れる水による土地の変化を区別しながら関連付ける。 |
| 流れる水の働きと土地の変化 | 土地のつくりと変化 | 学習上のつながり | 水による地形変化と、地層・火山・地震などの土地の成り立ちを混同しない。 |
| 月と星の見え方 | 月の形と太陽の位置 | 学習上のつながり | 第4学年の月・星の観察と、第6学年の月の形の見え方を分けて接続する。 |
| 生物と環境の関わり | 食べ物を通した生物の関係 | 同一公式項目内の細分化 | 食物関係を生物と環境の具体例として配置し、独立した公式内容項目と誤認させない。 |
| 燃焼の仕組み | 水溶液の性質 | 概念の橋渡し | 空気・物質の変化を考えるという共通性はあるが、直接の前提関係にはしない。 |

## 2. 探究の方法を横断してつなぐ候補

| 探究の力 | 関連する活動 | 設計上の注意 |
|---|---|---|
| 自然事象から問題を見いだす | 観察、比較、既習事項との関係付け | 単元固有の知識ではなく、探究過程の一部として管理する。 |
| 予想や仮説を立てる | 既習事項を基に予想し、根拠を言葉にする | 「予想」と「結果から導く結論」を混ぜない。 |
| 調べ方を計画する | 変える条件・そろえる条件の検討 | 条件制御を全学年で同じ水準とみなさず、学年ごとの重点を確認する。 |
| 目的に応じた観察・結果の記録 | 表、図、文章、数値などで整理する | 観察技能、記録技能、結果の解釈を必要に応じて分ける。 |
| 結果から結論を導く | 結果と予想を比較し、根拠を示す | 結果そのものと、結果に対する解釈を区別する。 |
| 根拠を基に説明・共有する | 他者の結果との比較、説明の見直し | 発表の上手さではなく、根拠と説明のつながりを中心にする。 |

## 3. 現時点でのデータ化ルール案

1. 項目間の関係は、単純な「前提／発展」だけでなく、関係の種類と根拠を持たせる。
2. 公式の学年配当と、プロジェクトが提案する学習上のつながりを別フィールドで管理する。
3. 公式内容の分割項目には、親となる公式項目への参照を持たせる。プロジェクト独自のIDと公式コードは別々に保持する。
4. 問題解決の力は、理科のA・B内容区分に混ぜず、横断的なスキル群として扱う。
5. 公式コードと学年配当を照合するまでは、関係候補を確定データとして教材推薦や学習順序の強制に使わない。

## 4. 次に確認すること

- 公式コード表82V12の理科の最小単位と、候補項目の対応
- 各候補の初出学年・継続学年・公式項目の親子関係
- 「物の性質と見分け方」などの表示名を公式内容に合わせて改めること
- 関係候補が学年順を不必要に固定しないか、学習指導要領解説と照合すること


## 追補：第4学年「雨水の行方」と土地の学び（2026-10-20）

第4学年B(3)「雨水の行方と地面の様子」に対応する候補 `jp.elem.science.rainwater-land-surface` を追加した。第5学年B(3)「流れる水の働きと土地の変化」と第6学年B(4)「土地のつくりと変化」への関連候補を、`grade-link-143` と `grade-link-144` として登録した。文部科学省解説には、この第4学年の内容が第5学年・第6学年の土地に関する学習につながることが明示されている。

2件は `related-learning` とし、学習順序を固定するものではなく、内容の関連を示す候補として `needs-review` にしている。

根拠資料：文部科学省「小学校学習指導要領（平成29年告示）解説 理科編」第4学年B(3) https://www.mext.go.jp/content/20211020-mxt_kyoiku02-100002607_05.pdf
