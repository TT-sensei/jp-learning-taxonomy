# 項目の統合・詳細保持レビュー（2026-10-24）

## 基本方針

一覧では大きな学習のまとまりを見せ、詳細では具体的な知識・技能・活動を残す。項目数を減らすこと自体は目標にしない。学ぶ力や目的が重なる項目を統合し、似ていても異なる学習活動・概念・発展段階は分けて残す。

統合時は次を確認する。

1. 統合前の説明にあった内容が、後継項目の詳細に引き継がれているか。
2. 学年の違いや学びの発展段階が、説明の中で分かるか。
3. prerequisite・related-learning・application などの関係が後継IDへ移されているか。
4. 公式コード対応表に旧IDの枠を残し、旧IDを `topicLifecycle: "superseded"` と `replacementTopicIds` で後継項目へ案内しているか。
5. 件数・manifest・検証結果を更新したか。
6. 公式資料との対応が未確認なら、統合したことを公式配当の確定と混同させていないか。

## 実施済み

### 国語：6組を統合

国語の表示対象を75項目から69項目に整理した。言葉の意味と語彙、表記のきまり、文の組み立て、情報の整理、叙述に基づく想像・推論、複数文章・資料の比較について、重なる項目をそれぞれ一つのまとまりにした。詳細説明は統合後に補強し、統合前の重要な観点が失われないようにした。

- `jp.elem.japanese.vocabulary-expansion` → `jp.elem.japanese.word-meaning`
- `jp.elem.japanese.kana-orthography` → `jp.elem.japanese.punctuation-and-notation`
- `jp.elem.japanese.connectives-and-modifiers` → `jp.elem.japanese.sentence-structure`
- `jp.elem.japanese.information-structure` → `jp.elem.japanese.compare-and-classify-information`
- `jp.elem.japanese.infer-from-text` → `jp.elem.japanese.read-between-the-lines`
- `jp.elem.japanese.compare-information-across-sources` → `jp.elem.japanese.compare-texts`

### 算数：比の学びを統合

2026-10-24に、「比の表し方と比べ方」と「比の値と等しい比」を一つの項目に統合した。後継項目は「比の表し方・比の値・等しい比」とし、比で表すこと、比の値を求めること、等しい比を見つけること、縮図などへの活用を詳細説明に含めた。

- `jp.elem.math.meaning-of-ratio` → `jp.elem.math.ratio`
- 旧IDは互換性のため保持し、後継項目を示す。
- 関係データは後継IDへ移行し、統合元と後継項目を直接結ぶ重複関係は削除した。
- 公式コード対応表の旧ID枠は残し、コード候補は後継項目で確認する扱いに変更した。
- 算数の表示対象は104項目から103項目、全教科の表示対象は265項目から264項目になった。

この統合は編集上の整理であり、公式な学年配当やコードの意味的対応が確定したことを意味しない。

## 似ているが、現時点では分けて残す項目

項目名や活動が似ている場合も、育てる力や扱う内容が異なるものは、安易に統合しない。次の組は現時点で分けて残し、詳細説明と公式資料の照合を優先する。

### 算数

- **「簡単な表とグラフ」／「表・棒グラフ」**：表を使って整理する基礎と、棒グラフで数量を比較する学びの発展を見分けられるようにする。学年候補も異なるため、公式資料との照合前に統合しない。
- **「概数・四捨五入・見積もり」／「計算の見積もりで答えを確かめる」／「見積もり・予想と確かめを学習全体で使う」**：概数の知識・計算場面での妥当性確認・教科横断的な問題解決の力を区別する。
- **「比例の関係」／「比例の関係を表・式・グラフで表す」**：比例の意味と複数の表現を使って捉える技能が重なるため、公式資料・学年範囲を確認した上で再判断する。現段階では、詳細の欠落を避けるため別項目とする。
- **「加法の意味」／「減法の意味」**：数量場面と演算の意味が異なるため統合しない。

### 社会

- **「食料生産とわたしたちの生活」／「農業の生産と食料」／「水産業の生産」**：食料生産を生活と結ぶまとめ、稲作を中心とした農業の具体的な学び、水産業の具体的な学びという役割を保つ。まとめ項目と具体的な事例項目は重複だけを理由に統合しない。
- **「自然災害と国土の保全」／「自然災害から地域を守る」**：国土・防災の仕組みと地域の安全を守る働きを区別し、学年と社会的な視点を確認する。
- **「資料を根拠に説明する」／「統計・グラフを読み取る」／「地図・地球儀を読み取る」／「年表・歴史資料を読み取る」**：横断的な説明力と、資料の種類に応じた読み取り技能を区別する。

### 理科

- **「目的に応じた観察」／「結果を記録・整理する」**：対象を観察する方法を選ぶことと、観察・実験結果を記録・整理することは異なる技能なので分けておく。
- **「自然事象から問題を見いだす」／「予想や仮説を立てる」／「調べ方を計画する」／「条件を制御して調べる」／「結果から結論を導く」**：探究の過程としてつながるが、各段階で求める力が異なるため、項目を維持して関係でつなぐ。
- **「水の温度と状態の変化」／「自然界の水の循環」／「天気と気温、自然界の水の様子」**：実験で調べる水の状態変化、自然界での水の移動、天気・気温との関係を区別する。相互の関連は詳細説明と関係データで示す。
- **「人の体のつくりと運動」／「人の体のつくりと働き」**：骨・筋肉など運動の仕組みと、呼吸・消化・排出・血液循環などの働きを区別する。

## 次のレビュー順

1. 国語の統合項目について、詳細説明に統合元の観点が残っているかを再点検する。
2. 算数は、項目をまとめる前に「数と計算」「図形」「測定・変化と関係」「データ活用」の各領域で、公式資料と学年範囲を照合する。
3. 社会・理科は、まとめ項目と具体的な内容項目、探究の横断技能と教科固有の知識・技能を区別して点検する。
4. 各回の変更後にデータ検証を実行し、統合による内容の抜け・参照切れがないことを確認する。
