# 理科・社会の分野別整理レビュー（2026-10-24）

## 目的

学年ごとのカードを並べるだけでなく、教科の中で「どんな領域の学びか」を見渡せるようにする。表示分類はプロジェクト独自の整理であり、学習指導要領の正式な項目区分・学年配当を置き換えるものではない。項目数を減らすこと自体は目標にせず、知識・技能・探究の段階が異なるものは分けて残す。

## 理科：4つの分野＋横断的な学び

理科の既存データには、学習指導要領上の大きな区分（A 物質・エネルギー／B 生命・地球）と、学習内容を見渡すためのクラスターがある。学習マップでは内容を探しやすくするため、クラスターから次の4分野に整理する。

- **エネルギー**：光・音、電気、磁石、力、運動など。
- **粒子**：物の形・体積・重さ、空気と水、温度による変化、溶け方、水溶液、燃焼など。
- **生命**：植物・動物の体、成長、誕生、人の体、生物どうしや環境との関わりなど。
- **地球**：太陽・月・星、天気、季節、雨水、流れる水、土地のつくりと変化など。
- **調べ方・科学的な探究**：問題を見いだす、予想する、計画する、観察する、条件を制御する、記録・整理する、結論を導く、説明・共有するなど。
- **分野をつなぐ見方**：水の循環や自然災害のように、複数の単元・分野をつないで考えるプロジェクト独自の横断項目。

「調べ方」は知識分野とは別の学びとして見せる。観察すること、記録すること、予想すること、条件を制御すること、結論を導くことは探究の流れでつながるが、それぞれ求める技能が異なるため、現時点では統合しない。

### 理科で分けて残す境界

- **物の形・体積と重さ／空気と水の性質／金属・水・空気と温度／水の温度と状態の変化／物の溶け方／水溶液の性質**：物質の性質を調べる点では関連するが、重さ・圧縮・温度変化・溶解・水溶液の性質は学習対象と問いが異なるため、別項目を維持する。
- **人の体のつくりと運動／人の体のつくりと働き**：骨・筋肉と運動の仕組み、呼吸・消化・排出・血液循環を区別する。
- **水の温度と状態の変化／天気と気温・自然界の水の様子／自然界の水の循環**：実験で調べる状態変化、天気や気温との観察、自然界での水の移動を区別し、関係でつなぐ。
- **流れる水の働きと土地の変化／土地のつくりと変化／自然災害と土地・気象**：水の作用、地層・火山・地震による土地の変化、災害への横断的な見方を区別する。
- **植物の発芽・成長・結実／植物の養分と水の通り道**：成長に必要な条件と、植物体内の養分・水の働きを区別する。

## 社会：内容領域ごとの8つのまとまり

社会は学年の列だけでなく、地理・地域のくらし・産業・歴史・政治・資料活用などの大きなまとまりで探せるようにする。data/topics.json の cluster を分類の正本にし、画面側の ID の一覧に依存しすぎない構成にした。

- **地域のようす・地図**：身近な地域、市区町村の変化、地域の仕事、地図と方位。
- **くらしを支えるしくみ**：消防・警察、廃棄物、水などの供給、地域の自然災害への備え。
- **都道府県の特色と地域づくり**：都道府県の位置・地形・産業、文化・年中行事、特色ある地域、地域の発展に尽くした先人。
- **日本の国土と自然**：日本の位置、地形・気候、自然環境とくらし、国土全体の自然災害・保全。
- **産業・情報・環境**：農業・水産業・林業、工業、交通・物流、情報産業、食料生産、環境保全。
- **歴史のうつりかわり**：古代から近現代までの社会・政治・文化の変化。
- **政治と世界**：憲法、国会・選挙、内閣・裁判所、地方公共団体、国際関係・国際協力。
- **資料を使って調べる**：現地調査、地図・地球儀、統計・グラフ、年表・歴史資料、根拠に基づく説明、比較、社会の課題についての判断。

### 社会で分けて残す境界

- **地域の安全を守る働き／自然災害から地域を守る／自然災害と国土の保全**：事故・火災への対応、地域の防災体制、国土の自然条件と防災・減災を分けて扱う。
- **食料生産とわたしたちの生活／農業の生産と食料／水産業の生産／森林資源と林業**：生産・輸入・流通・消費を結ぶまとめ、農業・水産業・林業それぞれの生産の特徴を区別する。
- **交通網と物流／工業生産と貿易**：人・物の移動を支える仕組みと、工業製品の生産工程・技術・貿易を区別する。
- **地域に伝わる文化・年中行事／県内の特色ある地域とまちづくり／地域の発展に尽くした先人**：文化の継承、地域の特色・協力、個人の具体的な働きという異なる問いを維持する。
- **資料を根拠に説明する／統計・グラフを読み取る／地図・地球儀を読み取る／年表・歴史資料を読み取る**：資料の種類ごとの読み取りと、複数資料を使って説明・判断する力を区別する。

## 実装・検証上の注意

- 社会の44項目に cluster を設定し、一覧のまとまりをデータ側で明示した。
- 理科は既存のクラスターを活用し、4分野・探究・横断的な見方に分けて表示する。
- 既存 topic ID と学習関係は維持する。今回の分類整理では項目の統合・削除を行わない。
- 学年、公式コード、内容対応は別途照合を継続する。データ検証の成功は、内容・学年配当の公式確認完了を意味しない。
