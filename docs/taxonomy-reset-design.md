# タクソノミーの再整理方針（ゼロベース案）

更新日：2026-10-19

## 目的

項目を細かく分類すること自体を目的にしない。子ども・先生が「今の学びは何を土台にしていて、次に何へつながるのか」を短い道すじで把握できることを優先する。

## 基本の形

1. **学びのまとまり**：最初に見る単位。例「たし算・ひき算」「かけ算」「わり算」。
2. **詳しい学習項目**：必要に応じて開く情報。既存の topic ID は教材参照との互換性のため維持し、大きなまとまりからリンクする。
3. **確認問題・つまずき・練習**：タクソノミーとは別の教材データで扱う。1つの誤答パターンごとにタクソノミー項目を増やさない。

## つながりの扱い

- 「先に学ぶとよい」「関係がある」「学んだことを使う」は意味を分ける。
- すべてを一本の必修ルートにしない。分岐・合流・行き来を認める。
- 根拠が薄い関係は無理につながず、確認中として残す。
- 学年は見通しのための候補であり、公式資料との照合前に断定しない。

## まず試す範囲

最初のモデルは、小学校1〜6年生の整数計算とする。大きなまとまりは「数のしくみ」「たし算・ひき算」「かけ算」「わり算」「計算を工夫し、確かめる」の5つ。細かな既存項目は、これらのまとまりの中に束ね、必要なときに開く。

試作ページ：[整数計算の学びの道すじ](../site/pathways.html)

## 既存データとの移行

- 初回は既存 ID や前提関係を一括削除・改名しない。
- 新しい大きなまとまりから実際に使われていない項目、重複項目、分割しすぎた項目を洗い出す。
- タクソノミーの整理と同時に公式コードや学年配当を確定したように見せない。
- つながりマップで使い勝手を確認してから、必要な項目の統合・旧項目の非表示・関係データの見直しへ進む。
