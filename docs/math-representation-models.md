# 算数の表現モデルを使った系統整理

## 目的

学習項目を「学年・単元名」の一覧だけで終わらせず、子どもが数量や図形の関係をどのような表現で捉え、別の表現へ移っていくかを記録する。ここでいう表現モデルは、出版社の図版を転載したものではなく、学習上の機能をプロジェクト独自に整理した分類である。

## 初期モデル

| 表現モデル | 主な役割 | 発展・接続を検討する例 |
|---|---|---|
| 具体物・操作 | 数量や図形の意味を実感する | 操作 → 図 → 式 |
| 部分と全体の図 | 全体・部分・差・増減を捉える | 具体物 → 部分全体図 → 式 |
| 配列・面積モデル | 乗法、分配、計算のきまりを視覚化する | 配列 → 長方形の分割 → 計算式 |
| 数直線 | 順序・大きさ・等間隔・数の位置を表す | 整数 → 分数・小数 → 比や比例の関係 |
| 線分図・テープ図 | 数量の対応、部分と全体、割合を長さで表す | 加減の関係 → 比・割合の関係 |
| 表・対応表 | 数量の対応や変化、データを整理する | 表 → 規則性の発見 → 式・グラフ |
| 式・関係式 | 数量関係を簡潔に表し、未知数を検討する | 場面・図 → 式 → 式の意味を説明 |
| グラフ | 変化や分布の傾向を読み取る | 表 → グラフ → 説明・判断 |
| 図形の構成図・展開図 | 平面と立体、構成要素や位置関係を行き来する | 実物 → 見取図・構成図 → 展開図 |

この表は検討の出発点であり、学年ごとの到達目標や唯一の学習順序を断定するものではない。

## データ

[`data/representation-models.json`](../data/representation-models.json) に、モデル ID、ねらい、関連する学習項目 ID、学年範囲を記録する。現時点ではすべて `needs-review` であり、関連項目の選定は確認中である。

## 参照資料の使い方

- 文部科学省の学習指導要領解説を基準に、学習内容の位置づけを確認する。
- 啓林館の「算数・数学 内容系統一覧表」などで、学年をまたぐ概念のつながりを比較する。
- 東京書籍の「領域別系統表」「図解系統表」「線分図・数直線の系統」などで、図的モデルや表現の発展を比較する。
- 各社の単元配列をそのまま全国共通の順序とみなさず、共通点と違いを記録する。
- 出版社の図版や本文は転載せず、プロジェクト独自の説明と関係データを作る。

参照先：
- 文部科学省「小学校学習指導要領解説 算数編」 https://www.mext.go.jp/a_menu/shotou/new-cs/1387014.htm
- 啓林館「授業支援・サポート資料」 https://shinko-keirin.co.jp/keirinkan/sho/sansu/support/
- 東京書籍「新編 新しい算数の資料ダウンロード」 https://ten.tokyo-shoseki.co.jp/text/shou//download/sansu/

## 次のレビュー

1. 既存93項目のそれぞれに、中心となる表現モデルを1つ以上割り当てるか判断する。
2. 同じ概念が学年を越えてどの表現で再登場するか確認する。
3. 表現モデル間の移行を「前提」と決めつけず、関連・発展・活用も使って記録する。
4. 比・割合・比例、分数・小数、乗法・除法、図形の構成など、表現を行き来する学習を重点レビューする。
