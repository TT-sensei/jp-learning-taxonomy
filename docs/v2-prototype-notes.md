# v2 画面試作メモ

## 作成したもの

site/v2/ に、学年・教科・キーワードから学習項目を見渡し、項目を開くと前提候補・発展・関連を確認できる静的試作を追加した。

## データ接続

- ../../data/topics.json を読み込む。
- ../../data/dependencies.json を読み込む。
- topicLifecycle: superseded は一覧から除外する。
- 学年表示は gradePlacement の初出候補・継続候補を優先して表示する。
- 学習関係の確認状態を表示し、未確認の関係を確定扱いしない。

## 制限

- 現在のデータに収録されている国語・算数・社会・理科のみを表示する。
- 他教科は対象範囲として案内するだけで、未収録の学習項目を生成しない。
- 復習診断・誤答別の復習先は未実装。前提候補は復習候補になり得るが、同義ではない。
- 学習目標の専用データ項目がまだ十分でないため、詳細画面は現行説明を中心に表示する。
- ネットワーク全体図は未実装。選択項目の直接関係を先に確認する構成とした。

## 次の検証

1. site/v2/ を Pages 上で開き、JSON相対パスが解決することを確認する。
2. 1〜6年、4教科、検索、項目詳細、関係リンクを実機確認する。
3. タブレット横向き・縦向き、スマートフォン、キーボード操作を確認する。
4. 既存 scripts/validate.mjs と Actions の検証に影響しないことを確認する。
5. 算数の復習候補データを、つまずき別に根拠付きで設計する。
6. その後に全教科の学習データ拡張と移行計画を進める。
