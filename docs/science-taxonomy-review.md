# 理科タクソノミー 初期レビュー記録

更新日：2026-10-20  
対象：共通データ `data/topics.json` の理科48項目と、統合前の分類設計・レビュー経緯

## 設計の考え方

理科は、学年ごとの内容だけを並べると、学年を越えて育つ科学的な概念や問題解決の力が見えにくくなる。そのため、初期案では次の3つを分けて整理する。

1. **公式の内容区分**：A「物質・エネルギー」、B「生命・地球」
2. **学年横断の概念の柱**：「エネルギー」「粒子」「生命」「地球」
3. **問題解決の力・科学的な探究**：問題を見いだす、予想する、方法を考える、結果を整理する、結論を導くなど

3はA・Bと同列の公式内容区分として扱うのではなく、複数の内容で使われる横断的な力を見通すためのプロジェクト独自の整理とする。

## 初期項目のまとまり

| まとまり | 含めた項目の例 | 照合時のポイント |
|---|---|---|
| 物質の性質・状態変化 | 物の性質、空気、水の状態変化、物の溶け方、燃焼 | 「物の性質」と「粒子の存在・結合・保存性」などの概念の柱を、根拠なく一対一対応させない。 |
| 電気・磁石・力・運動 | 回路、電気の働き、電流がつくる磁力、振り子、てこ | 学年別の公式内容との対応を確認し、一般的な「力と物の動き」のような広すぎる候補を分割・削除する。 |
| 光・音 | 光の進み方、音の性質 | 小学3年の内容との対応を確認し、観察する性質と説明する規則性の粒度をそろえる。 |
| 生物の体・成長・環境 | 植物の成長、動物の体、発芽・結実、人の体、生物と環境 | 観察対象・知識内容と、比較・関係付けなどの思考方法を混在させない。 |
| 地球・天気・天体・土地 | 太陽と影、天気、月と星、流れる水、土地のつくり | 学年別内容を照合し、月の見え方と月・太陽の位置関係など、近い項目の境界を明確にする。 |
| 観察・問題解決の過程 | 問題設定、予想、計画、条件制御、記録、結論 | 学年ごとに重視される問題解決の力と、全学年を通じて育てる技能を分けて記録する。 |

## 優先して見直す候補

- **「物の形・体積と重さ」**：第3学年A(1)に合わせて説明を更新済み。公式コード表との照合は未完了。
- **「風とゴムの力の働き」**：項目名・説明は第3学年A(2)に合わせて修正済み。内容の細部と公式コードは引き続き確認する。
- **「自然界の水の循環（横断的な見方）」**：複数学年をつなぐ項目として整理し、公式A・B内容区分と別の横断概念に分類済み。関連先の妥当性は引き続き確認する。
- **「自然災害と土地・気象（横断的な見方）」**：理科の土地・気象との関連に限定する説明に更新し、社会科の防災行政・地域の備えとは区別するよう分類を変更済み。
- **「食べ物を通した生物の関係」**：生物と環境の関係の下位項目にするか、独立項目とするかを検討する。
- **問題解決の力の学年帯**：比較、関係付け、条件制御、多面的な考察を特定学年だけの能力と見なさず、公式解説の記述に基づいて初出・重点・継続を分ける。
- **概念の柱との対応**：現段階の候補ラベルは機械的な仮対応を含むため、個別の内容と公式解説の図表・説明を確認してから確定する。

## 学年配当と公式コードの扱い

- `candidateGrades` は照合を始めるための仮候補であり、公式な学年配当を意味しない。
- 公式解説の学年別内容に照らし、初出学年・継続学年・根拠箇所を別々に記録する。
- 公式コードは、コード表の実データと一致を確認するまで付与しない。
- 教科書の単元名・掲載順を、全国共通の唯一の分類や公式コードの代わりにしない。
- 学習項目の関係は、内容を照合した後に「前提」「関連」「発展」などを区別して提案する。

5. 学習項目間の関係候補を、公式解説で明示される接続とプロジェクト独自の関連に区別して見直す。

## 第2回：公式内容区分との境界を明確化（2026-10-20）

文部科学省「小学校学習指導要領（平成29年告示）解説 理科編」の学年別内容を再確認し、次の修正を行った。

- 第3学年A(1)「物と重さ」について、`matter` を物の形・体積と重さの関係に焦点化した。
- 第4学年A(1)「空気と水の性質」では、閉じ込めた空気の圧縮と押し返す力、水が圧し縮められないことの両方を説明に含めた。
- 第4学年A(2)「金属，水，空気と温度」では、体積の変化・温まり方と、水が水蒸気や氷に変わることを同じ公式内容内のプロジェクト独自の細分化候補として区別した。
- 第4学年B(3)「雨水の行方と地面の様子」を独立項目として追加した。雨水の流れる方向と地面の傾き、しみ込み方と土の粒の大きさを扱う。
- 第4学年B(4)「天気の様子」から雨水の流れ・しみ込みを切り分け、天気・1日の気温変化・自然界の水の様子を関連付けて説明した。
- `water-cycle` と `earth-disasters` は、公式のA・B内容区分に並ぶ独立項目ではなく、複数の内容をつなぐ横断的な見方として草案・本データの分類を変更した。
- 第5学年の流れる水・天気、第6学年の植物の養分と水の通り道、土地のつくりと変化、月と太陽について、公式解説の範囲が見えるよう説明を具体化した。
