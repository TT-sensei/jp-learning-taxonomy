# 学習指導要領コード表 82V12 の確認記録（2026-10-20）

## 確認できたこと

- 文部科学省の教育データ標準ページに掲載されている小学校学習指導要領コード表の対象版は **82V12（平成29年告示・バージョン1.2）**。
- 公表日は2022年3月14日。
- 公式一覧ページ：<https://www.mext.go.jp/a_menu/other/data_00001.htm>
- CSV配布先：<https://www.mext.go.jp/content/20230901-mxt_syoto01-000010374_27.csv>
- 公式一覧ページ上で小学校82V12のCSVリンクを確認した。

## 今回できなかったこと

この実行環境ではCSVの本文を取得・解析できなかった（ウェブ閲覧側はCSVのコンテンツ形式に対応せず、ファイル取得も失敗）。よって、コードの文字列や本文を検索結果だけから推測して登録することは避けた。

## データ上の扱い

- data/curriculum-code-mapping.json の公式コードは未照合のまま維持する。
- コードが空欄であることは、実データとの照合前に誤ったコードを登録しないための明示的な状態である。
- 公式CSVを取得できる環境で、教科・学年・コード・本文を解析し、各プロジェクト項目を公式記述に照合する。
- 公式内容のまとまりに対応する項目と、資料活用技能などプロジェクト独自の横断項目を区別する。独自項目には公式コードを無理に割り当てない。
- 照合後は出典、照合日、判断理由、複数コード・対応なしの理由を記録し、scripts/validate.mjs で整合性を確認する。

## 参照

文部科学省「教育データ標準」：<https://www.mext.go.jp/a_menu/other/data_00001.htm>


## 取得方法の再確認

文部科学省ページのリンク番号をたどり、82V12のExcel版（`https://www.mext.go.jp/content/20230901-mxt_syoto01-000010374_28.xlsx`）とCSV版（`https://www.mext.go.jp/content/20230901-mxt_syoto01-000010374_27.csv`）の両方を確認した。Excel版もこの実行環境では取得時にコンテンツ形式の制約で読み込めず、CSV同様に行データの照合には使えなかった。

補助的な構造化データとして、第三者による「学習指導要領LOD」も見つかった（<https://jp-cos.github.io/Dataset>）。ただし、今回確認できた検索結果には82V12の完全なコードデータが含まれていると確証できず、公式表の代わりにコードを登録する根拠にはしない。今後はLODの対象バージョンと更新状況を確認し、82V12と同一内容だと検証できた範囲だけを照合補助に使う。
