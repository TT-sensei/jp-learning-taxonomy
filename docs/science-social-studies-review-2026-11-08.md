# 理科・社会タクソノミー点検記録（2026-11-08）

## 1. 点検の位置付け

対象は共通データ `data/topics.json` の理科48項目、社会44項目。文部科学省「小学校学習指導要領（平成29年告示）解説 理科編・社会編」を基準資料として、学年配当、項目の境界、説明文、学習目標を確認した。

この点検は、データの内容を改善するための編集レビューであり、全項目の公式な学年配当や教育的妥当性を最終確定するものではない。既存のレビュー状態は維持し、確認していない項目を「確認済み」には変更していない。

## 2. 理科の点検・修正

### 確認した構成

- 第3学年：物の性質、風・ゴム、光・音・磁石・電気、身近な生物、太陽と地面
- 第4学年：空気・水・金属と温度、電気の働き、季節と生物、月と星、人の体の運動、雨水、天気
- 第5学年：物の溶け方、振り子、電磁石、植物の発芽・成長・結実、動物の誕生、天気、流れる水
- 第6学年：燃焼、水溶液、てこ、電気の利用、植物の養分、人の体の働き、月と太陽、土地のつくり、生物と環境
- 問題解決の力：比較、関係付け、条件制御、多面的な考察を学年段階に応じて整理

### 修正内容

| 項目 | 修正内容 |
|---|---|
| 昆虫など身近な動物の体と育ち方 | 第3学年の目標から季節変化の記述を外し、体のつくり・育ち方の比較に整理。季節による生物の変化は第4学年の項目で扱うことを明確化 |
| 電気の働き | 乾電池の数・つなぎ方と豆電球の明るさ・モーターの回り方の関係に具体化。第6学年の電気の変換・利用と区別 |
| 自然事象から問題を見いだす／調べ方を計画する | 第3〜6学年で問題設定・計画の質が発展することを説明に追記 |
| 比較して考える／関係付けて考える／条件を制御して調べる／多面的に考えて説明する | 第3・4・5・6学年で中心となる問題解決の力を明示し、互いの違いとつながりを整理 |
| 結果から結論を導く・予想や仮説を立てる | 結果と解釈、予想の根拠を区別して扱うよう説明を明確化 |

## 3. 社会の点検・修正

### 確認した構成

- 第3学年：身近な地域、市区町村、地図、地域の仕事、地域の安全
- 第4学年：県の地理・産業・文化、先人、飲料水等の供給、廃棄物、防災
- 第5学年：日本の国土、農業・水産業・工業、情報産業、環境、森林、自然災害
- 第6学年：日本の歴史、政治・憲法、国際社会
- 横断的な技能：現地調査、資料活用、地図・地球儀、統計・グラフ、年表・歴史資料、比較・判断

### 修正内容

| 項目 | 修正内容 |
|---|---|
| 地図・地球儀を読み取る | 第3学年の方位・地図記号、第4学年の都道府県、第5学年の地球儀・世界地図・緯度経度、第6学年の歴史地図等の活用へと段階を明確化 |
| 統計・グラフを読み取る | 数値の大小・変化を読む基礎から、学年の学習対象に応じた資料の読み取り、複数資料の関連付けへと整理 |
| 年表・歴史資料を読み取る | 第3・4学年の地域の移り変わりや先人の学習と、第6学年の通史的な歴史学習を区別 |
| 観察・聞き取り・現地調査 | 第3学年の身近な地域調査から、第4学年の県内調査、第5・6学年の複数情報の照合へと発展を明確化 |
| 資料を根拠に説明する | 事実と解釈の区別、複数資料の関連付け、根拠の明示を学年段階に応じて整理 |
| 社会の課題について考え判断する | 地域の安全、生活を支える事業、産業・環境、政治・国際社会へと学習対象に応じて考える構成を明確化 |

## 4. 継続して注意する点

- 社会の「交通網と物流」「食料生産とわたしたちの生活」「自然環境と人々のくらし」などは、公式の独立した内容項目をそのまま写したものではなく、複数の学習内容をつなぐプロジェクト独自のまとめ項目として扱う。
- 理科の「自然界の水の循環」「自然災害と土地・気象」も、独立した学年別の公式内容項目ではなく、関連する学習をつなぐ横断的な整理項目として扱う。
- 学年配当・レビュー状態は、根拠の確認が終わるまで既存の暫定状態を維持する。
- 今回は項目数を増減せず、説明と学習目標の精度を高める修正を中心に行った。

## 6. v2画面の表示・操作点検

データだけでなく、`site/v2/index.html`・`app.js`・`styles.css` の表示ロジックも確認し、次を修正した。

- 複数学年にまたがる理科・社会の技能項目で、詳細画面が「初出候補3年」だけを表示し、継続する学年が見えにくくなる問題を修正。継続候補が未入力でも、項目の学年配当から継続学年を補って表示する。
- 理科の分野を「物質・エネルギー」→「生命・地球」→「問題解決の力」→「横断的な見方」の順に、社会を第3学年→第4学年→第5学年→第6学年→「調査・資料活用（横断）」の順に表示する。
- 理科4項目（問題の発見、予想、計画、結論）と社会7項目（調査、根拠を基にした説明、判断、比較、地図、統計、年表・資料）に、3〜6年の学年段階ごとの発展を表示するデータを追加した。計11項目・44段階。
- 子ども向けの短い説明はそのままにし、詳細画面に「先生・保護者向けの補足」を折りたたみ表示できるようにした。
- 検索語が学びの道すじにも反映されるようにした。
- 学年段階のカードは、段階数に応じて列数が変わるようにし、4段階が不自然に折り返されにくい配置にした。
