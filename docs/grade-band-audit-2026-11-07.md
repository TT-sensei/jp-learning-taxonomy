# 小学校14教科等・学年段階の確認監査（2026-11-07）

## 目的と扱い

14教科等の学習項目について、学年タグが文部科学省の現行学習指導要領・解説に示された学年段階と矛盾しないかを確認した記録。学年は学習マップ上の候補であり、出版社ごとの年間指導計画や学校独自の単元配列を全国共通の順序として示すものではない。

## 確認結果

| 教科等 | 現在の学年整理 | 確認・注意点 |
|---|---|---|
| 生活 | 1・2年 | 生活科の対象学年と整合。活動・単元の順は地域・学校の実態で異なる。 |
| 音楽 | 1〜6年 | 低・中・高学年の2学年段階で発展する継続領域。全学年で同じ水準という意味ではない。 |
| 図画工作 | 1〜6年 | 低・中・高学年の段階別内容がある。表現・鑑賞の大領域としてまとめており、材料・用具や表現の発達段階は今後の詳細化対象。 |
| 家庭 | 5・6年 | 小学校家庭科の対象学年と整合。 |
| 体育 | 1〜6年 | 運動領域は低・中・高学年の3段階。保健領域は3・4年と5・6年に分かれる。運動の大領域は継続項目としてまとめており、種目別の段階差は詳細化余地がある。 |
| 外国語活動 | 3・4年 | 中学年の外国語活動として整理。 |
| 外国語 | 5・6年 | 高学年の外国語科として整理。聞く・話す・読む・書くの5領域を区別。 |
| 道徳 | 内容項目ごとに学年段階を反映 | 22項目のうち、相互理解・寛容は3〜6年、真理の探究・よりよく生きる喜びは5・6年。全項目を全学年で同じように扱う意味ではない。 |
| 総合的な学習の時間 | 3〜6年 | 第3学年以上の授業時数と整合。具体的な学習テーマは各学校が定める。 |
| 特別活動 | 全学年を基本とし活動により段階差 | 学級活動・学校行事は全学年。クラブ活動は主として4年生以上。児童会は全児童で組織され、中学年の運営参加も想定される。 |

## 今回の修正

- 児童会の組織づくりと計画・運営の候補学年を4〜6年から3〜6年へ変更。
- 児童会は全児童で組織され、中学年が運営に参加する場合もあることを根拠・注記に反映。
- 学びの道すじの表示も、全学年の参加と中学年の運営参加を区別する表現に修正。
- 教科×学年の集計を再計算。

## 継続確認が必要な点

1. 音楽・図画工作・体育の大領域項目は6年間を通した継続領域として扱っている。低・中・高学年の発達段階を学習者向け表示でどこまで細分化するかは今後の設計課題。
2. 特別活動の児童会活動・学校行事は学校規模や教育課程によって参加方法が異なる。候補学年を固定的な資格要件として表示しない。
3. 道徳は各学年段階に示された重点を基準とする。必要に応じて他段階の内容を関連的・発展的に扱うことを妨げない。
4. 出版社の年間指導計画は題材配列の比較資料として利用し、特定出版社の順序を全国共通の必修順序として採用しない。

## 監査の限界

これは学年範囲の大きな矛盾を見つけるための監査であり、全375レコードの学習内容・公式コード・出版社別単元配列を個別に最終承認したものではない。各項目の reviewStatus は既存の確認状態を維持し、未レビュー項目を確認済みに変更していない。
