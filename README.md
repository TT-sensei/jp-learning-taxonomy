# JP Learning Taxonomy（日本版 学習タクソノミー）

小学校全教科の学習内容を、学年・領域・学習項目・学習項目間のつながりで整理する、オープンなデータセットと学習マップを目指すプロジェクトです。

## 目的

- 日本の小学校で学ぶ内容を、参照元と確認状況が分かる構造化データとして公開する
- 学習項目どうしの前提関係・関連・発展を可視化する
- TT-sensei の教材や、ほかの教材・学習支援ツールから再利用できる共通 ID を整備する
- GitHub Pages で動く静的な学習マップを提供する

## 開発方針

- HTML / CSS / JavaScript と JSON を基本とし、バックエンド・データベースを使わない
- 外部 API、API キー、従量課金サービス、必須 CDN を使わない
- 学習項目の ID は学年や表示名が変わっても維持できる値にする
- 学習指導要領の記述を大量転載せず、出典を記録し、説明文は独自の表現で作成する
- 根拠が確認できない前提関係を断定しない
- 教科の特性に応じて「前提」「関連」「発展」を使い分ける。すべての教科を一本道の習得順序として扱わない
- 公開前に出典・ライセンス・学習内容の妥当性を確認する

## 教科の対象

国語、社会、算数、理科、生活、音楽、図画工作、家庭、体育、外国語活動、外国語、道徳、総合的な学習の時間、特別活動。

## 現在の進捗

### 算数：初期試作

算数の主要領域について、学習項目77件と学習項目間の関係46件を登録しています。項目は6学年にまたがりますが、学習指導要領のすべての記載を網羅した確定版ではありません。内容や関係はレビュー前の草案として管理しています。

- [学習項目データ](data/topics.json)
- [学習項目間の関係](data/dependencies.json)
- [学習指導要領・領域参照データ](data/curriculum-standards.json)
- [学習マップ（試作）](site/)

現在の領域参照 ID はプロジェクト独自の分類であり、文部科学省の正式な学習指導要領コードではありません。正式コードとの対応付けは今後の作業です。

## ディレクトリ構成

- `data/topics.json` — 学習項目
- `data/dependencies.json` — 学習項目間の関係
- `data/curriculum-standards.json` — 出典と領域レベルの参照情報
- `data/resources.json` — TT-sensei 等の関連教材
- `data/manifest.json` — データセットの版・件数・確認状況
- `schema/` — データ仕様
- `scripts/validate.mjs` — データの参照整合性を確認するスクリプト
- `site/` — 静的な学習マップ
- `PROVENANCE.md` — 出典と確認方針
- `LICENSE-DATA.md` — データの利用条件に関する方針

## データの検証

Node.js がインストールされた環境でリポジトリのルートから `node scripts/validate.mjs` を実行すると、ID の重複、参照切れ、前提関係の不一致、前提関係の循環などを確認できます。追加パッケージは不要です。

## 算数のカバレッジ確認

追加候補と今後の確認項目は [算数カバレッジ確認メモ](docs/math-coverage-review.md) に記録しています。追加した項目はすべてレビュー前の草案です。

## 次の作業

1. 算数の学習項目と関係を、学年・領域別に教員視点でレビューする
2. 学習指導要領コード表（82V12）との対応を確認し、正確なコードを登録する
3. ID参照、関係の循環、出典、ライセンス、学年の整合性を検証する
4. 算数で仕様が固まったら、他教科のデータ設計に展開する
5. TT-sensei の各教材と共通 ID で関連づける

## データ・コードの利用条件

コード、独自の文章、学習項目データ、外部資料は、利用条件が異なる場合があります。公開前に [LICENSE-DATA.md](LICENSE-DATA.md) と [PROVENANCE.md](PROVENANCE.md) を確認してください。出典 URL を記載するだけで第三者資料の再配布が許可されるわけではありません。
