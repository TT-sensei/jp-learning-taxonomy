# JP Learning Taxonomy（日本版 学習タクソノミー）

小学校全教科の学習内容を、学年・領域・学習項目・学習項目間のつながりで整理するオープンなデータセットと、学習マップを目指すプロジェクトです。

## 目的

- 日本の小学校で学ぶ内容を、参照元と確認状況が分かる構造化データとして公開する
- 学習項目どうしの前提関係・関連・発展を可視化する
- TT-sensei の教材や、他の教材・学習支援ツールから再利用できる共通 ID を整備する
- GitHub Pages で動く静的な学習マップを提供する

## 開発方針

- HTML / CSS / JavaScript と JSON を基本とし、バックエンド・データベースを使わない
- 外部 API、API キー、従量課金サービス、必須 CDN を使わない
- 学習項目の ID は学年や表示名が変わっても維持できる安定した値にする
- 学習指導要領の記述をそのまま大量転載せず、出典を記録し、説明文は独自の表現で作成する
- 根拠が確認できない前提関係を断定しない。教科の特性に応じて「前提」「関連」「発展」を使い分ける
- 公開前に出典・ライセンス・学習内容の妥当性を確認する

## 教科の対象

国語、社会、算数、理科、生活、音楽、図画工作、家庭、体育、外国語活動、外国語、道徳、総合的な学習の時間、特別活動。

※ 教科によって学習内容の構造は異なります。すべてを一本道の習得順序として扱わず、表現・鑑賞・実技・探究・態度などの特性を反映します。

## ディレクトリ構成

- `data/topics.json` — 学習項目
- `data/dependencies.json` — 学習項目間の関係
- `data/curriculum-standards.json` — 学習指導要領等の参照情報
- `data/resources.json` — TT-sensei 等の関連教材
- `data/manifest.json` — データセットの版・件数・状態
- `schema/` — データ仕様
- `site/` — 静的な学習マップ
- `PROVENANCE.md` — 出典と確認方針
- `LICENSE-DATA.md` — データの利用条件に関する方針

## 現在の状態

初期設計・試作段階です。サンプル項目は仕様確認用であり、網羅性や公式性を示すものではありません。レビュー前の項目には `draft` などの状態を明記します。

## データの利用について

コード、データ、文章、外部資料は権利や利用条件が異なる場合があります。公開前に `LICENSE-DATA.md` と `PROVENANCE.md` を確認してください。ライセンス表記があることだけを理由に、第三者資料の再配布が許可されているとは判断しません。

## 開発の進め方

1. データ仕様と出典ルールを固める
2. 算数「数と計算」を小さな試作範囲として検証する
3. ID・参照整合性・関係の妥当性・ライセンスを点検する
4. 学習マップを実装する
5. 教科ごとにレビューしながら対象を広げる
