# JP Learning Taxonomy（日本版 学習タクソノミー）

小学校全教科の学習内容を、学年・領域・学習項目・学習項目間のつながりで整理する、オープンなデータセットと学習マップを目指すプロジェクトです。

## 目的

- 日本の小学校で学ぶ内容を、参照元と確認状況が分かる構造化データとして公開する
- 学習項目どうしの前提関係・関連・発展を可視化する
- TT-sensei の教材や、ほかの教材・学習支援ツールから再利用できる共通 ID を整備する
- GitHub Pages で動く静的な学習マップを提供する

## 開発方針

- HTML / CSS / JavaScript と JSON を基本とし、バックエンド・データベースを使わない
- 外部 API、API キー、従量課金サービス、必須 CDN を使わない
- 学習項目の ID は学年や表示名が変わっても維持できる値にする
- `name` は整理用の項目名として残し、子ども向け画面では `studentName` と `studentDescription` を使う。表示名は「何を学ぶか」が伝わる日常的な言葉にし、元の分類や出典情報とは分けて管理する
- 学習指導要領の記述を大量転載せず、出典を記録し、説明文は独自の表現で作成する
- 根拠が確認できない前提関係を断定しない
- 教科の特性に応じて「前提」「関連」「発展」を使い分ける。すべての教科を一本道の習得順序として扱わない
- 公開前に出典・ライセンス・学習内容の妥当性を確認する

## 教科の対象

国語、社会、算数、理科、生活、音楽、図画工作、家庭、体育、外国語活動、外国語、道徳、総合的な学習の時間、特別活動。

### 算数：初期試作

学習マップでは、選んだ項目を「前に学んだこと → 今見ている学び → これから学ぶこと」の道すじとして表示し、前後の項目を選ぶと、その学びを中心に道すじをたどれます。関係の理由も表示します。つながりのない項目は無理に線で結ばず、未整理であることを明示します。表示上の道すじは編集上の関係候補であり、公式の必修順序を表すものではありません。 教科を選び、学年を「全学年」のままにすると、1〜6年生の項目を横並びで見比べる学年マップも表示します。学年マップは各項目を初出学年の候補に1回だけ配置し、継続学年の候補を項目内に表示します。初出・継続とも公式の学年配当ではなく、確認中の候補です。

現在の領域参照 ID はプロジェクト独自の分類であり、文部科学省の正式な学習指導要領コードではありません。正式コードとの対応付けは未完了です。公式コード表の実データ照合が終わるまでは、コードを推測して登録しません。各項目の学年は現時点では確認候補であり、公式な学年配当を保証しません。表現モデルの対応も一部の項目に限られ、レビュー中です。

### 国語：分類構造の初期草案（共通マップに統合済み）

国語は学年ごとの一覧を主軸にせず、学習内容のまとまりを軸に整理します。現在は次の6領域・11まとまりに、75件の項目候補を整理しています。低学年（1・2年）・中学年（3・4年）・高学年（5・6年）は見通しのための仮区分です。

- 言葉の特徴や使い方に関する事項
- 情報の扱い方に関する事項
- 我が国の言語文化に関する事項
- 話すこと・聞くこと
- 書くこと
- 読むこと

[国語の分類・項目候補（草案）](data/japanese-language-taxonomy-draft.json)
- [国語タクソノミーの初期レビュー記録](docs/japanese-language-taxonomy-review.md)

これは分類と項目の草案であり、公式な学年配当や学習指導要領コードを確定したものではありません。文部科学省の国語編解説を出典候補として登録し、言葉・表記、情報の収集と出典、話し合い、書く目的や形式、文章の種類や表現効果などの候補を追加しました。公式の内容構成との対応先をデータに追加しました。個々の項目の照合は未完了です。重複候補と境界の考え方は[初期レビュー記録](docs/japanese-language-taxonomy-review.md)にまとめ、次に学年別内容との照合、初出・継続学年の確認、項目の統合・分割を進めます。

### 社会：分類構造の初期草案

社会は第3〜6学年の内容を骨格に、地域学習、国土・産業、歴史、政治・国際社会を整理します。地図・統計・年表・聞き取りなどの資料活用技能は、単元知識と分けて横断的な候補として管理します。候補43件は共通の学習マップ用データにも統合しました。現在はまず教科内の学年間のつながりを整理し、地域から都道府県・日本へ広がる見方や、歴史の時代のつながりなどを追加しています。算数との教科横断的な関係は登録済みの候補を維持し、今後あらためて整理します。

現在は43件の学習項目候補を登録した初期草案です。公式解説との初回照合で第3学年の「地域の発展に尽くした先人」の候補漏れを確認し、追加しました。学年配当・公式コード・全項目の網羅性は未確定です。

- [社会の分類・項目候補（草案）](data/social-studies-taxonomy-draft.json)
- [社会タクソノミーの初期レビュー記録](docs/social-studies-taxonomy-review.md)
- [社会タクソノミー：項目間の関係候補](docs/social-studies-relationship-review.md)

文部科学省の社会編解説を参照し、公式内容の大きなまとまりと草案の候補を照合し始めました。公式内容を親項目、プロジェクト独自の細分化を子項目として対応づける作業、地域固有の教材と全国共通の学習枠の分離、公式コード表の実データとの照合は継続中です。

### 理科：分類構造の初期草案（共通マップに統合済み）

理科は、公式の内容区分である「A 物質・エネルギー」「B 生命・地球」と、学年を越える概念の柱「エネルギー」「粒子」「生命」「地球」を分けて整理します。また、観察・実験を通じた問題解決の力は、A・Bと同列の公式区分ではなく、横断的な観点として別に記録します。

現在は47件の学習項目候補を、物質・エネルギー、生物、地球、問題解決の過程などに整理しています。学年は照合前の仮候補であり、公式の学年配当や学習指導要領コードを確定したものではありません。

- [理科の分類・項目候補（草案）](data/science-taxonomy-draft.json)
- [理科タクソノミーの初期レビュー記録](docs/science-taxonomy-review.md)
- [理科：学年別内容との対応確認（第1回）](docs/science-grade-alignment-review.md)
- [理科タクソノミー：項目間の関係候補](docs/science-relationship-review.md)

文部科学省の理科編解説を参照して45候補の初回レビューを行い、その指摘を受けて2候補を追加・分割し、現在は47候補を管理しています。公式内容より広い候補や、分割・追加が必要な項目を[対応確認記録](docs/science-grade-alignment-review.md)に整理しています。学年別内容との対応は引き続き草案であり、正式コードの照合や全項目の確定は未完了です。次は公式コード表の実データと照合し、確実に対応できる範囲だけを登録します。

## ディレクトリ構成

- `data/topics.json` — 学習項目
- `data/dependencies.json` — 学習項目間の関係
- `data/curriculum-standards.json` — 出典と領域レベルの参照情報
- `data/resources.json` — TT-sensei 等の関連教材
- `data/manifest.json` — データセットの版・件数・確認状況
- `schema/` — データ仕様
- `scripts/validate.mjs` — データの参照整合性を確認するスクリプト
- `site/` — 静的な学習マップ
- `PROVENANCE.md` — 出典と確認方針
- `LICENSE-DATA.md` — データの利用条件に関する方針

## データの検証

Node.js がインストールされた環境でリポジトリのルートから `node scripts/validate.mjs` を実行すると、ID の重複、参照切れ、前提関係の不一致、前提関係の循環などを確認できます。追加パッケージは不要です。

## 複合項目の分割と旧ID

分割対象と移行方針は [分割提案](data/topic-split-proposals-math-a.json) と [移行・関係設計](data/topic-split-migration-math-a.json) を参照してください。旧親項目は `topicLifecycle: superseded` と `replacementTopicIds` を付けて互換性のためデータに残し、学習マップの一覧では非表示にしています。新しい子項目は追加済みですが、学年配当・項目粒度・公式コードは引き続き確認中です。

## 算数のカバレッジ確認

追加候補と今後の確認項目は [算数カバレッジ確認メモ](docs/math-coverage-review.md) に記録しています。追加した項目はすべてレビュー前の草案です。

## 残っている確認作業

1. 文部科学省の学習指導要領コード表（82V12）のCSV実データと各項目を照合し、確実なコードだけを登録する
2. 追加した13項目の学年・粒度を学習指導要領解説および複数の系統資料でレビューする
3. 関係の妥当性、表現モデル、出典、ライセンスを継続確認する
4. 算数データの構造が安定した後、他教科のデータ設計へ展開する
5. TT-sensei の各教材と共通 ID で関連づける

## データ・コードの利用条件

コード、独自の文章、学習項目データ、外部資料は、利用条件が異なる場合があります。公開前に [LICENSE-DATA.md](LICENSE-DATA.md) と [PROVENANCE.md](PROVENANCE.md) を確認してください。出典 URL を記載するだけで第三者資料の再配布が許可されるわけではありません。
