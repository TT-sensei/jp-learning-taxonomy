# JP Learning Taxonomy（日本版 学習タクソノミー）

小学校全教科の学習内容を、学年・領域・学習項目・学習項目間のつながりで整理する、オープンなデータセットと学習マップを目指すプロジェクトです。

## 目的

- 日本の小学校で学ぶ内容を、参照元と確認状況が分かる構造化データとして公開する
- 学習項目どうしの前提関係・関連・発展を可視化する
- TT-sensei の教材や、ほかの教材・学習支援ツールから再利用できる共通 ID を整備する
- GitHub Pages で動く静的な学習マップを提供する

## EDU KITとの連携

この学習マップは、教材の見た目や仕組みを決める前に、学習目標と学びのつながりを考えるための参照データです。[EDU KIT](https://tt-sensei.github.io/edu-kit/) からも開けます。EDU KITは教材設計・共通基盤の入口、JP Learning Taxonomyは学習内容を整理する参照先として役割を分けます。項目の学年配当や関係は確認中の候補を含むため、公式の必修順序として扱わず、学習指導要領や教科書と照合してください。

## 参考プロジェクトとの比較・再設計方針

Marble Skill Taxonomy などの公開プロジェクトから、学習項目の粒度、関係の強さと理由、出典管理、データ検証、学習経路の見せ方を参考にします。ただし、項目内容は日本の小学校学習指導要領（平成29年告示）を基準に独自に整理し、海外の基準や他国の教科書内容は移植しません。比較結果と設計方針は[参考プロジェクト比較・日本版の再設計方針](docs/reference-projects-and-japan-curriculum-design-2026-10-20.md)に記録しています。

## 開発方針

- HTML / CSS / JavaScript と JSON を基本とし、バックエンド・データベースを使わない
- 外部 API、API キー、従量課金サービス、必須 CDN を使わない
- 学習項目の ID は学年や表示名が変わっても維持できる値にする
- `name` は整理用の項目名として残し、子ども向け画面では `studentName` と `studentDescription` を使う。表示名は「何を学ぶか」が伝わる日常的な言葉にし、元の分類や出典情報とは分けて管理する
- 学習項目間の関係も、元の `rationale` を維持しながら、子ども向けには `studentRationale` を表示する。前提・関連・発展などの関係を、必ず通る一本道の順番として扱わない
- 算数の表し方マップは、表し方の名前と役立つ場面を `studentName` / `studentPurpose` に分け、関連する学びも子ども向けの名前・説明で表示する
- 学習指導要領の記述を大量転載せず、出典を記録し、説明文は独自の表現で作成する
- 根拠が確認できない前提関係を断定しない
- 教科の特性に応じて「前提」「関連」「発展」を使い分ける。すべての教科を一本道の習得順序として扱わない
- 公開前に出典・ライセンス・学習内容の妥当性を確認する

## 教科の対象

国語、社会、算数、理科、生活、音楽、図画工作、家庭、体育、外国語活動、外国語、道徳、総合的な学習の時間、特別活動。

学習マップでは、選んだ項目を中心に「先に学ぶとよいこと」「関係する学び」「この学びから広がること」を分けて表示します。関係の種類と理由も表示し、単に関係がある学びを「必ず先に学ぶ」と誤解させないようにしています。教科を越えたつながりも表示対象です。つながりは編集上の候補であり、公式の必修順序を表すものではありません。教科を選び、学年を「全学年」のままにすると、1〜6年生の学びを横並びで見比べる学年マップが表示されます。学年マップは候補初出学年に配置し、継続学年の候補を項目内に表示します。初出・継続とも公式の学年配当ではなく、確認中の候補です。国語は学年配当の候補が一律に未確認のため、誤解を避けて学習内容のまとまりごとに表示します。

### 国語：分類構造の初期草案（共通マップに統合済み）

- 言葉の特徴や使い方に関する事項
- 情報の扱い方に関する事項
- 我が国の言語文化に関する事項
- 話すこと・聞くこと
- 書くこと
- 読むこと

### 社会：分類構造の初期草案

社会は第3〜6学年の内容を骨格に、地域学習、国土・産業、歴史、政治・国際社会を整理します。地図・統計・年表・聞き取りなどの資料活用技能は、単元知識と分けて横断的な候補として管理します。候補44件は共通の学習マップ用データにも統合しました。現在はまず教科内の学年間のつながりを整理し、地域から都道府県・日本へ広がる見方や、歴史の時代のつながりなどを追加しています。算数との教科横断的な関係は登録済みの候補を維持し、今後あらためて整理します。

現在は44件の学習項目候補を登録しています。再照合により、以前第3学年に置いていた「地域の発展に尽くした先人」は第4学年内容（4）の候補に修正し、第3学年内容（3）「地域の安全を守る働き」に対応する消防・警察の候補学年を整理しました。また、第5学年の自然災害・国土保全の候補項目を追加しました。学年配当・公式コード・全項目の網羅性は引き続き確認中です。

### 理科：分類構造の初期草案（共通マップに統合済み）

理科は、公式の内容区分である「A 物質・エネルギー」「B 生命・地球」と、学年を越える概念の柱「エネルギー」「粒子」「生命」「地球」を分けて整理します。また、観察・実験を通じた問題解決の力は、A・Bと同列の公式区分ではなく、横断的な観点として別に記録します。

## ふりがなの自動解析

学習マップでは、既存のふりがな辞書を残したまま、Kuroshiro による自動ふりがなを詳細欄で試せます。導入方法・ライセンス・注意点は[自動ふりがなの試験導入](docs/furigana-kuroshiro.md)を参照してください。自動解析は読みを推定するため、文脈によって変わる読みは確認が必要です。

## データの検証

Node.js がインストールされた環境でリポジトリのルートから `node scripts/validate.mjs` を実行すると、ID の重複、参照切れ、前提関係の不一致、前提関係の循環などを確認できます。追加パッケージは不要です。

## 複合項目の分割と旧ID

分割対象と移行方針は [分割提案](data/topic-split-proposals-math-a.json) と [移行・関係設計](data/topic-split-migration-math-a.json) を参照してください。旧親項目は `topicLifecycle: superseded` と `replacementTopicIds` を付けて互換性のためデータに残し、学習マップの一覧では非表示にしています。新しい子項目は追加済みですが、学年配当・項目粒度・公式コードは引き続き確認中です。

## 学習指導要領コード表の実データ確認（2026-10-20）

文部科学省の「教育データ標準」ページで、小学校学習指導要領コード表の対象版が **82V12（平成29年告示・バージョン1.2、2022年3月14日公表）** であることを確認した。公式ページは [文部科学省 教育データ標準](https://www.mext.go.jp/a_menu/other/data_00001.htm)、CSVへのリンク先は [小学校学習指導要領コード表 82V12（CSV）](https://www.mext.go.jp/content/20230901-mxt_syoto01-000010374_27.csv)。

この環境ではCSV本体の取得がコンテンツ形式の制約で失敗し、コード・本文・学年等の行データを直接検査できなかった。そのため、未確認コードを推測で入力する変更は行っていない。data/curriculum-code-mapping.json の276項目は引き続き未照合として保持する。次の作業ではCSVを取得可能な環境で読み込み、公式コード・本文・学年・教科を実データから抽出してから、項目ごとに「直接対応」「複数コード対応」「プロジェクト独自項目で直接対応なし」を判断する。

今回確認したのは公式の版と配布URLまでであり、個別項目の公式コード照合完了を意味しない。
